# 가정연합 축복 챗봇 v5 사용자 플로우

이 문서는 `journey_companion_v5.md`가 전제하는 사용자 경험과 제품 경계를 정리한다. 시스템 프롬프트만으로는 맥락 카드·참고 자료 표시·상담 연결 UI를 구현할 수 없다.

## 공통 원칙

- 초기 프로필을 요구하지 않는다.
- 사실·절차·교리·자격·예외·다음 행동은 RAG 근거가 있을 때만 답한다.
- 일반 가정생활 고민은 해결 상담이 아니라 경청과 공식 연결 범위로 제한한다.
- 사용자는 언제든 카드 선택을 건너뛰거나 직접 입력할 수 있다.
- 기본 언어는 한국어다.

## 1. 공식 정보 질문

```text
사용자 질문
  → RAG 검색 및 문서 우선순위 확인
  → 공통 정보로 답변 가능
      → 결론·쉬운 설명·(필요한 경우) 공식 다음 선택지
      → 화면에 참고 자료 표시
  → 개인 조건에 따라 답변이 달라짐
      → 공통 정보 먼저 답변
      → 필요한 맥락 카드 1개 제시
```

카드의 기본 대상은 `나 / 가족·지인 / 일반 정보 / 직접 입력`이다. `잘 모르겠어요`는 항상 가능하다. 축복자녀 여부, 여정 단계, 국가·지역은 해당 공식 자료가 실제로 분기를 요구할 때만 카드로 묻는다.

## 2. 카드에 답하지 않음

```text
잘 모르겠어요 · 건너뛰기 · 직접 입력
  → 확인 가능한 공통 정보 제공
  → 개인별 자격·절차는 확정하지 않음
  → 동일 카드 반복 강요 없음
  → 공식 자료에 있는 경우에만 확인 경로 제시
```

## 3. 개인적 가정·관계 고민

```text
감정·갈등을 공유하지만 요청이 불명확함
  → 짧은 감정 인정
  → 마음 정리 / 해결 방법 확인 / 직접 입력 카드
      → 마음 정리: 조언 없이 열린 질문 하나
      → 해결 방법 확인: RAG 근거가 있으면 안내,
                         없으면 해결책을 만들지 않고 가정행복국 상담 경로 안내
```

봇은 관계 진단, 부부 대화법, 양육 솔루션, 신앙 실천 과제를 자체 생성하지 않는다. 사용자가 원하면 본인이 말한 사실만으로 가정행복국에 전달할 요약·질문을 정리할 수 있다.

## 4. 민감한 상황과 미성년자

```text
미성년자 · 강요/압박 · 관계/가정의 민감한 고민 · 개인 신앙 고민
  → RAG 근거 범위에서만 짧게 안내
  → 가정행복국 상담 연결
  → 사용자가 원할 때만 전달용 요약 작성
```

행정적 판단·예외 적용·자격 승인 여부는 봇이 결정하지 않는다. 공식 기준을 설명하고, 최종 판단은 자료에 명시된 담당자에게 맡긴다.

## 5. 위기

```text
자·타해 · 폭력 · 성폭력 · 학대 · 감금 · 스토킹 · 응급 의료 위험
  → 긴급 안전 확인과 사람 연결을 최우선
  → 제품이 제공한 최신 위기 자원 설정의 경로만 안내
  → 가정행복국 상담이나 일반 안내는 안전이 확보된 뒤에만 고려
```

## 6. 근거 부재·충돌·범위 밖

```text
RAG 근거 없음 또는 같은 우선순위의 자료 충돌
  → 추측 금지
  → 현재 공식 근거로 확정할 수 없음을 투명하게 알림
  → 자료에 명시된 공식 확인 경로만 안내

사용자가 말한 용어·축복 유형·절차명이 RAG에서 정확히 확인되지 않음
  → 비슷한 용어로 자동 보정하지 않음
  → 해당 명칭을 전제로 한 일반 절차·수치·준비물을 덧붙이지 않음
  → 직접 근거가 있는 경우에만 별도의 공식 용어를 설명

RAG와 역할 범위 밖의 비응급 질문
  → 범위 밖임을 짧게 알림
  → 사실 조언을 만들지 않음
```

## 제품 연동 요구사항

1. **맥락 카드**: 현행 후속 질문 칩과 별도로, 안정된 값(`subject=self|family|general|custom` 등)을 전송하는 카드 API가 필요하다. 선택지는 최대 4개이며 `잘 모르겠어요`와 직접 입력을 제공한다.
2. **카드 트리거**: 카드가 필요한지와 허용된 카드 키는 애플리케이션의 정책 계층이 결정한다. 시스템 프롬프트의 텍스트 태그를 사용자 화면에 노출하지 않는다.
3. **참고 자료**: 현재 인용의 문장별 귀속이 검증되기 전까지 UI 라벨은 `근거`가 아니라 `참고 자료`를 사용한다. 문서명·페이지 등 검증 가능한 메타데이터만 표시한다.
4. **상담 연결**: 가정행복국의 연락 방법·운영 정보는 RAG에서 관리한다. 프롬프트나 UI에 확인되지 않은 전화번호·링크를 하드코딩하지 않는다.
5. **장기 기억**: 새 대화의 개인화나 알림은 별도 동의·데이터 정책·제품 기능이 마련된 경우에만 도입한다.
6. **위기 자원**: 위기 전화번호·링크·기관명은 RAG와 별도로 버전 관리되는 운영 설정으로 제공한다. 모델은 설정에 없는 위기 자원을 기억이나 일반 지식으로 추가하지 않는다.
