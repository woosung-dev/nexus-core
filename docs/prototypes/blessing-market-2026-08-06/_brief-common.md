# 공통 빌드 브리프 — blessing-market-2026-08-06 (8회차, 3안 전부 적용)

이 라운드의 단일 명제: **시판 가능한 상용 제품 셸.** 6회차까지 반려된 원인은
"정체성을 크롬(레이아웃·은유)에 넣은 것" — 이번엔 크롬은 중립 제품 셸이고,
개성은 봇 콘텐츠(카드·아바타·카피)가 낸다. 10~20년차 디자이너의 마감 밀도가 목표다.
AI slop으로 읽히는 모든 관행 금지.

## 산출 형식

- 자립형 단일 HTML(외부 요청은 웹폰트 CDN만 허용), 데스크톱 1440 우선 + 390 대응
- 한 파일 안 3뷰: **랜딩(기본)** / **#home(로스터)** / **#chat(대화)** — 해시 라우팅으로 전환,
  `hashchange` 대응, 내비에 세 뷰 진입점
- 목데이터·목대화·아바타 규칙은 같은 폴더 `_content.md`를 그대로 사용(변형 금지 —
  3안 대조 성립 조건). 로스터는 JS 배열 + 렌더 함수로 구현하고 **N 스위치(8/24/60)** 데모
  컨트롤을 #home에 노출(60은 `_content.md`의 결정적 합성 규칙으로 생성)

## 콘텐츠-불가지론 셸 4원칙 (반려 피드백 — 최우선)

1. 도메인 은유(서고·창구·관인·선언 등)를 레이아웃에 하드코딩하지 않는다.
   도메인 맛은 봇 설명·태그·아바타 등 콘텐츠 레벨로만.
2. 로스터는 N-가변 컴포넌트: 그리드/리스트 + 검색 + 카테고리 칩(태그 합집합 파생) +
   빈 상태 + 스켈레톤 상태. 봇이 3개여도 60개여도 성립해야 한다.
3. 자동 아바타 필수(`_content.md` 시드 규칙). 로봇 얼굴·이모지 금지.
4. 절대 서약형 플랫폼 카피 금지("근거 없는 답은 하지 않습니다" 류) — 근거·인용 관련
   신뢰 표현은 봇별 속성 배지/카피와 인용 컴포넌트(칩·각주·스니펫)로만.

## 실측 토큰 (프리미엄 6곳 + 한국어 조판 10곳 실측의 합의점 — 지키면 비싸 보인다)

- 잉크: 제목 #17~#1f급 최암부, 본문은 한 단계 아래(#2e~#3a급). **순검정 금지**
- 표면: 니어화이트 배경 + 순백 카드(명도차 5 이하) 또는 다크 등가. 보더 1px 잉크 6~10% alpha
- radius 3값 이내 / 그림자 2단(rest·lift)만 / 노이즈·텍스처 사실상 0
- 액센트 면적: 뷰포트의 1% 미만 (CTA·포커스·마커에만)
- 모션: 호버 120~160ms ease-out, 진입 opacity+translateY≤16px 400ms 스태거 60ms, 그 이상 금지.
  `transition: all` 금지, `prefers-reduced-motion` 대응
- 한글 조판: 본문 15~16px, 행간 1.5~1.62, 자간 0~-0.01em. 디스플레이 행간 1.25~1.38,
  자간 -0.02~-0.03em(**하한 -0.04em**). 웨이트는 400↔700 큰 점프(중간 웨이트 금지).
  헤드라인은 `white-space:pre-wrap`으로 사람이 6~12자씩 개행. `word-break:keep-all` +
  `overflow-wrap:break-word` 전역, `line-height` 항상 명시
- 카피: 메인 헤드라인 미완결 종결(~하게/~도록/~까지), 본문 해요체 통일, 어절 3~6개
