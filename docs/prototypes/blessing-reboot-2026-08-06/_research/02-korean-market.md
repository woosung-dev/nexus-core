# 국내(한국) AI 챗봇/상담봇 제품 디자인 리서치

조사일: 2026-08-06
조사자: 시니어 프로덕트 디자이너 리서처 (에이전트)
방법: WebSearch/WebFetch, 일부 사이트는 `insane-search` (Jina Reader, curl 직접 프로브)로 CSS/HTML 원본까지 내려받아 실측. 접근 실패 항목은 각 절에 명시.

---

## 0. 조사 방법 및 접근 실패 로그

- **네이버 클로바X**: 공식 도메인 `clova-x.naver.com` DNS 자체가 사라짐(NXDOMAIN). 나무위키 확인 결과 **2026-04-09 서비스 종료**. 대체 소스: 나무위키, 종료 보도(ZDNet Korea, MS투데이), 후속 서비스 '네이버 AI탭' 관련 디자인나침반(designcompass.org) 기사 2건 — 단, 이 두 기사에는 색상/폰트 등 픽셀 단위 정보가 없어 기능 설명 위주로만 반영.
- **뤼튼(wrtn.ai)**: `WebFetch` 직접 호출이 HTTP 402(Payment Required)로 차단됨 → Jina Reader(`r.jina.ai`)와 `curl`로 우회, HTML·CSS 원본을 직접 파싱해 실제 서체·색상 변수를 확인함(가장 신뢰도 높은 실측 데이터).
- **위택스봇**(공공기관 챗봇 실증 사례): `curl`로 CSS 원본을 직접 확보해 색상·서체·라운딩·이미지 자산을 실측. 국내 공공 챗봇의 "촌스러움"을 추측이 아니라 코드 레벨로 확인한 유일한 사례.
- **KRDS(범정부 UI/UX 디자인시스템)**: 공식 색상 hex 값은 Figma/HTML Component Kit 배포본에만 있어 웹 크롤링으로는 확보 불가 — 구조적 규칙(13단계 명도, 60-30-10 비율, WCAG 대비값)만 확보.
- **토스 디자인 시스템(TDS)**: 비공식 정리 사이트(oh-my-design.kr)를 통해 색상/타이포/스페이싱/라운딩 수치를 확보. 토스 공식 폰트 파일(Toss Product Sans)은 일반 배포되지 않음.
- **채널톡**: 공식 블로그 2건(2021 UI 개편, 2024 리브랜딩)에서 정성적 서술은 확보했으나 정확한 hex 값은 비공개.

## 1. 뤼튼 (wrtn.ai)

**서체**: 실측 결과 별도 웹폰트 CDN(`cdn.jsdelivr.net/gh/orioncactus/pretendard`)에서 **Pretendard**를 직접 로드. 폴백 스택은 `"Pretendard", "Apple SD Gothic Neo", -apple-system, BlinkMacSystemFont, "Segoe UI", ... , "IBMPlexMono-Regular"`. 코드/모노스페이스 영역은 `IBMPlexMono-Regular` → `IBM Plex Mono` → Pretendard 순.
`word-break: keep-all` 클래스가 실제 CSS 번들에 존재(어절 단위 줄바꿈 명시 적용).

**색상**: CSS 변수에서 `--function_red_2: #FF5D44`, `--function_red_3: #D92800`, 실제 사용 빈도 상위 hex는 `#F54211`, `#D33717` — 브랜드가 "Inspire Red"라 부르는 색은 순수 빨강이 아니라 **주황에 가까운 톤다운 레드(#D92800~#F54211 대역)**. 보조로 바이올렷 그라디언트(`#727cff → #3683f0`, `#A788FD → #DCD5FF`)를 히어로/CTA 강조에 사용.

**레이아웃/모티브**: 브랜드 리뉴얼(2023, BAT 대행) 이후 "원(circle)"을 핵심 그래픽 모티프로 채택 — 히어로 모션, 버튼, 로고 등에 원형 반복. 라운딩 스케일은 4/6/8/10/12/16/20px + `9999px`(완전 원형 pill)로 다층 구성.

**채팅 UI 구조**: 홈이 곧 채팅 입력창(챗GPT류 랜딩과 유사) + 도구 카드형 그리드("블로그", "자기소개서" 등 프리셋 카드에 썸네일 이미지). 모델 배지(GPT-5 등)를 아이콘+텍스트로 노출해 "여러 모델을 고른다"는 정보성 신뢰 신호를 준다.

**카피 톤**: "무료로 회원가입" 같은 짧은 CTA, 존댓말이지만 군더더기 없는 명령형("로그인 후 파일 또는 사진을 첨부해 주세요"). 광고성 수사 대신 기능 설명 위주.

## 2. SKT 에이닷 (A.)

**정체성 변화가 핵심 사실**: 2022년 출시 후 "캐릭터 꾸미기"(3D 아바타, 헤어·의상·소품 스토어) 중심으로 성장했으나, **2024년 7월 개편에서 게임·캐릭터 커스터마이징 요소를 걷어내고 AI 기능에 집중**하는 방향으로 선회. 2024년 8월(3.0.0)부터는 "챗T"가 멀티 LLM 에이전트(7종 모델 지원)로 전환.

**디자인 시사점**: 캐릭터/젠지 감성의 스킨 경제로 시작했다가 실용 AI 도구로 회귀한 궤적은, "귀여움 연출"이 장기적으로 신뢰형 AI 상담 제품의 정체성과 충돌한다는 신호로 읽을 수 있음 — 페르소나가 강한 마스코트는 초기 화제성엔 유리하지만 실질 사용성 지표(에이전틱 작업 완료)로 갈수록 부담이 됨.

**개인화 홈**: 콘텐츠 추천을 한 화면에 모으는 방향으로 UX 전면 개편(2023, 2024 지속). 온보딩 단계 단축(2단계 회원가입)도 병행.

## 3. 네이버 클로바X → AI탭 (전환 사례)

**서비스 종료 사실**: CLOVA X(2023-08-24 출시)와 검색형 AI '큐(Cue:)'가 **2026-04-09 나란히 서비스 종료**. 네이버는 "축적된 기술·데이터는 AI탭 고도화에 활용"한다고 공식 발표.

**후속 서비스 'AI탭'**: 별도 챗봇 앱이 아니라 **네이버 통합검색 화면 안의 탭 하나**로 흡수(통합·뉴스·쇼핑 탭과 나란히 배치). 탭을 누르는 순간 대화형 인터페이스가 열리고, 후속 질문·옵션 비교·예약/구매 같은 행동까지 이어지도록 설계. 2026-04 베타 → 2026-05 말 전체 확대 → 2026-06 정식 출시, 약 2개월 만에 누적 400만 사용자.

**디자인 함의(가장 중요한 발견)**: 별도의 "AI 챗봇 앱/사이트"라는 카테고리 자체가 네이버 안에서는 실패했고, **검색 결과 자리에 대화형 UI를 이식하는 방식**이 채택됨. 이는 "챗봇을 별도 랜딩으로 독립시키기보다 기존 신뢰받는 진입점(검색창) 안에 자연스럽게 녹이는 편이 채택률이 높다"는 실증 사례로, 상담봇 UI를 설계할 때 참고할 만한 전략적 시사점.

## 4. 카카오 챗봇 생태계 (카카오톡 채널/오픈빌더, 아숙업)

**카카오 디자인 시스템 실측치**:
- 브랜드 옐로우: 로그인 배경 `#FEE500`(공식 규정상 색조 변경·그라디언트 적용 금지), 마케팅 옐로우 `#FAE100`
- 뉴트럴: 배경 `#FFFFFF`, 텍스트 `#333333`, 보조텍스트 `#888888`, 서피스 `#EEEEEE`, 보더 `#DBDBDB`
- 전용 서체: **KakaoBig**(디스플레이 53.82px/700/행간66px, 헤딩 30px/700/행간40px), **KakaoSmall**(본문 14px/400/행간21px, 캡션 12px/400/행간18px) — 로그인 버튼 라벨만 OS 시스템 폰트, 개발자 문서는 Pretendard
- 라운딩: 로그인버튼 12px, 검색 18px, 마케팅배너 16px, 푸터 24px, 필터 30px, 완전원형 `999px`
- 로그인 버튼 스펙: 심볼(말풍선) `#000000`, 라벨 `rgba(0,0,0,0.85)`

**챗봇(오픈빌더) UI 관행**: 상담톡/친구톡의 "일반 버튼"은 말풍선 내부, "바로연결 버튼"은 말풍선 하단 노출 — 이 **말풍선+하단버튼** 구조가 국내 사용자에게 가장 익숙한 챗봇 패턴(카카오톡 자체 UX 관성). 버튼형 퀵리플라이가 텍스트 입력보다 압도적으로 선호됨(오탈자·모호성 회피).

**아숙업(AskUp)**: 업스테이지가 카카오톡 채널에 얹은 챗봇으로 런칭 3일 만에 채널 친구 3만 돌파. OCR+GPT 결합, 눈 달린 캐릭터형 아바타가 프로필 이미지 역할. 브랜드 확장(레몬 스파클 하이볼 등 굿즈)에서는 라이트옐로우+민트 컬러로 "청량함"을 표현 — 챗봇 자체는 카카오톡 UI 셸을 그대로 쓰기 때문에 브랜드 표현의 자유도는 프로필 이미지·말투·이모지 정도로 제한적임(카카오톡 플랫폼 종속의 전형).

## 5. 채널톡 (channel.io) — B2B 상담위젯의 리브랜딩 궤적

2021년 UI 개편과 2024년 전면 리브랜딩, 두 시점의 변화가 뚜렷한 방향성을 보여줌.

**2021년 개편**:
- 채팅 버튼 배경을 컬러 강조 → **흰색 배경 + 부드러운 컬러 처리**로 전환("기존 버튼이 색상으로 과하게 강조되어 모바일에서 콘텐츠 집중을 방해했다"는 자체 진단)
- 말풍선 컬러감을 "뉴트럴한 방향"으로 순화
- 라운지(대화 목록)를 "군더더기 없이 깔끔하게" 리뉴얼
- 라벨 버튼 도입 후 새 메시지 수신 시 자동 축소 — 상시 노출되는 위젯이 콘텐츠를 가리지 않도록 하는 축소 인터랙션

**2024년 리브랜딩**:
- 서체를 Pretendard와 유사한 인상이되 **획 끝에 채널톡 고유의 곡선·말림**을 적용한 전용 서체로 교체(더 굵고 견고한 인상)
- 심볼을 "눈"에서 "입"으로 변경 — 마스코트성(캐릭터 눈)에서 채팅 서비스 본연의 은유(대화하는 입)로 이동, 작은 사이즈에서도 인식성 개선
- 배경을 그라디언트(자주색→자주색) 단색으로, 원형 배경 → 모서리가 둥근 사각형으로 변경
- AI 챗봇 'ALF'의 톤을 "귀여운 친구"에서 "차분한 어시스턴트"로 재정의
- 한/일/영 워드마크를 별도 제작해 해외 진출 대응

**시사점**: 두 번의 리브랜딩 모두 "귀엽고 튀는 마스코트성"을 걷어내고 "차분하고 절제된 어시스턴트"로 수렴하는 동일한 방향. AI 상담봇이 성숙기에 접어들수록 캐릭터성보다 절제된 어시스턴트 톤이 채택되는 패턴이 SKT 에이닷, 채널톡 두 사례에서 공통 확인됨.

## 6. 공공기관 챗봇 — 위택스봇 실측 사례 (촌스러움의 코드 레벨 증거)

`chatbot.wetax.go.kr`(위택스 세금 상담 챗봇, 2026-08 기준 운영 중)의 HTML/CSS를 직접 받아 실측.

**기술 스택 자체가 신호**: `jquery-3.1.1.min.js`(2016년 릴리스), `slick.js`(캐러셀/롤링배너 라이브러리) 를 그대로 로드. 롤링배너 라이브러리가 상담봇에 붙어있다는 것 자체가 "안내창구가 아니라 홍보판" 관성을 보여줌.

**서체**: CSS 412줄 전체에 `font-family` 선언이 **단 한 건도 없음** — 웹폰트를 전혀 지정하지 않고 OS 기본 서체(Windows는 맑은 고딕, macOS는 애플 시스템 폰트)에 전적으로 의존. Pretendard 같은 통일 서체 전략이 전무.

**색상 팔레트**: 실사용 hex 상위값이 `#3b6db6`(파랑), `#009ea1`(청록), `#8f4ebd`(보라), `#706CD1`(바이올렛), `#373295`(남보라), `#339d3b`(초록), `#2496fd`, `#0d72ec`, `#ff0000` 등 **최소 8개 이상의 상호 무관한 색상군이 한 서비스 안에 공존**. 토스(주조색 1개 `#3182f6` + 뉴트럴 그레이스케일)나 카카오(옐로우 1개 + 그레이스케일)의 "단일 브랜드 컬러 + 그레이스케일" 원칙과 정반대. 게다가 그라디언트도 `linear-gradient(#FCFCFC, #C5DDEF)`, `linear-gradient(to left, #80b6e7, #2496fd)` 등 파란 계열 안에서도 톤이 제각각.

**컴포넌트**: `border-radius` 값이 `2px, 5px, 10px, 15px, 15.19px(추정 반올림 오차), 17px, 18px` 등 **정수 스케일(예: 4/8/12/16 배수)이 전혀 없이** 산발적. 라디오 버튼은 CSS `appearance` 대신 `bg_radio.png` / `bg_radio_on.png` 래스터 이미지로 구현(레티나에서 흐릿해질 수밖에 없는 구조). 아이콘도 전부 PNG(`ico_menu.png`, `ico_send.png`, `ico_faq.png` 등) — SVG 아이콘 시스템 부재로 확대 시 계단현상 발생.

**단위 체계 붕괴**: 같은 파일 안에서 `font-size: 1.4rem`과 `font-size: 13px`가 동시에 쓰임 — 서로 다른 시기에 다른 개발자가 이어붙인 흔적이 코드에 그대로 남아, 실제 렌더링 크기가 화면마다 미묘하게 어긋날 가능성이 높음.

**국민비서 '구삐'**: 2020년 마스코트 대국민 공모로 선정된 토끼 로봇 캐릭터. 관공서 특유의 "공모전으로 마스코트를 정한다"는 절차 자체가 다수결 타협의 산물이 되기 쉬워, 특정 브랜드 정체성을 관통하는 일관된 톤을 만들기 어려운 구조적 원인 중 하나.

**KRDS(범정부 UI/UX 디자인시스템)의 자체 진단**: 2025-01 KRDS 정식 공개 배경 설명에서 "기관마다 통합검색 아이콘 위치가 다르다", "로고 사용이 기관별로 불일치(태극마크 vs 개별 로고)" 등이 문제로 지목됨 — 즉 공공 UI의 촌스러움은 미학적 실패이기 이전에 **거버넌스 부재(수백 개 기관이 각자 발주)로 인한 일관성 붕괴**가 근본 원인. KRDS는 이를 해결하려 표준형 서체로 **Pretendard GOV**를 지정하고, 색상은 정부청색/정부회색/정부적색 3색을 13단계 명도로 체계화, 60-30-10 색상 비율 원칙과 WCAG 대비값(3:1/4.5:1/7:1/15:1)을 명문화했지만 — 위택스봇 실측에서 보듯 **레거시 서비스에는 아직 소급 적용되지 않은 상태**(신규/개편 사업에만 순차 적용 중인 것으로 추정).

## 7. 금융권 — 토스 고객센터 챗봇 (긍정 대조군)

토스 기술 블로그(`toss.tech`) "눈 대신 귀로 느낄 수 있는 챗봇 흐름 만들기"에서 확인:

- **구조**: 안내 메시지 + 버튼형 선택지의 계층 구조. 상위 메뉴 선택 → 해당 답변 + 새 하위 버튼 세트로 전환(예: "송금" 선택 → "송금 한도가 궁금해요" / "송금 한도를 변경하고 싶어요" 버튼 노출)
- **패턴 자체는 카카오식 버튼형 UI와 동일**하지만, 접근성 디테일에서 차이가 남: 버튼 선택 시 해당 값이 "내가 보낸 메시지"로 채팅창에 표시(발화 이력이 시각적으로 남음), `scrollIntoView()` 후 ~1초 지연 뒤 `focus({preventScroll:true})`로 포커스 이동을 부드럽게 처리, 스크린리더 전용 안내 문구("아래 메뉴 버튼을 선택해 주세요") 삽입, `aria-live="polite"`로 상담원 입력 상태를 음성 안내, 송수신 시 효과음으로 청각 피드백.
- **시사점**: "버튼형 선택지"라는 패턴 자체는 국내 어디서나 동일(카카오톡 관성)하지만, **세련됨의 차이는 패턴이 아니라 마이크로 디테일(포커스 이동 타이밍, 스크린리더 대응, 상태 피드백)에서 갈린다.**

**토스 디자인 시스템(TDS) 실측 수치** (oh-my-design.kr 정리본):
- 색상: Primary `#3182f6`(hover `#2272eb`), 텍스트 `#191f28`, 강조본문 `#4e5968`, 보조텍스트 `#8b95a1`, 서피스 `#f2f4f6`, 보더 `#e5e8eb`, 위험 `#e42939`
- 타이포(전용서체 Toss Product Sans, 비공개 배포): H1 36px/700/행간54px, H2 30px/600/행간45px, H3 24px/600/행간36px, H4 22px/600/행간33px, Body 16px/400/행간24px, Body Small 14px/400/행간21px
- 스페이싱: 4/6/8/16/24/32px, 라운딩: 4/6/8(sm~md), 버튼 8~16px(사이즈별), xlarge 버튼 높이 56px·라운딩 16px·라벨 17px/600
- **핵심 원칙**: 주조색 1개 + 뉴트럴 그레이스케일 6단계로만 구성 — 위택스봇의 8색 난립과 정반대 구조

## 8. "고급스럽다"고 평가받는 국내 서비스가 공유하는 요소

**토스**: 흰 배경 + 넓은 여백 + 단일 브랜드 블루(`#3182f6`) + 전용 서체(Toss Product Sans, 라틴/숫자를 한글 비례에 맞춰 별도 제작)로 "군더더기 없음"을 시각화. 은행 앱 NPS 조사에서 7개 주요 은행 앱 중 최고점(26.3점)을 기록한 배경으로 "미니멀·감성적 UX"가 반복 언급됨.

**배달의민족**: 반대로 "고급스러움"이 아니라 "귀여운 을지로 간판체" 계열의 자체 서체(한나체, 주아체, 도현체 등)로 승부 — 1960~70년대 국내 간판을 모티브로 한 삐뚤빼뚤한 조형을 의도적으로 살려 세련됨 대신 **친근함·B급 유머**의 톤을 구축. "세련됨=미니멀함"이라는 공식과는 다른, 톤 일관성 자체가 브랜드 자산이 되는 대안 경로.

**공통분모(토스/카카오/채널톡)**: 
1. 주조색 1개 + 뉴트럴 그레이스케일(5~8단계)로 팔레트를 제한
2. 서체를 시스템 폰트에 맡기지 않고 전용/커스텀 웹폰트를 명시 로드(토스=Toss Product Sans, 카카오=KakaoBig/Small, 뤼튼·채널톡=Pretendard 계열)
3. border-radius가 4/8/12/16px 같은 배수 스케일로 정리되어 있음(위택스처럼 2/5/10/15/17/18px가 뒤섞이지 않음)
4. 아이콘/장식 요소가 SVG 벡터(래스터 PNG 캐러셀·배너 남용 없음)
5. 마스코트/캐릭터가 있더라도(카카오프렌즈, 뤼튼 등) UI 크롬 자체는 캐릭터에 의존하지 않고 타이포+컬러+여백으로 구조를 완성 — 캐릭터는 "장식"이지 "정보구조의 대체재"가 아님

## 9. 종합 체크리스트

### 세련됨을 만드는 요소
- [ ] 한글 서체는 시스템 기본값에 맡기지 않고 웹폰트로 명시 로드(Pretendard 또는 전용 서체) — 폴백 스택까지 챙긴다(`"Pretendard", "Apple SD Gothic Neo", -apple-system, ...`)
- [ ] `word-break: keep-all`(+ 필요 시 `overflow-wrap: anywhere` 보완)을 한국어 본문에 기본 적용해 어절 단위 줄바꿈 보장
- [ ] 주조색은 1개만 정하고 나머지는 그레이스케일 5~8단계로 구성(토스=블루 1개, 카카오=옐로우 1개)
- [ ] border-radius는 4px 배수 등 하나의 스케일로 통일(예: 4/8/12/16px)하고 다중 코너 라운딩(`0 15px 15px 15px` 같은 비대칭)은 의도가 명확할 때만 예외적으로 사용
- [ ] 아이콘·장식은 SVG로 통일, 래스터(PNG) 아이콘·롤링배너 라이브러리(slick.js류) 사용을 피한다
- [ ] 타이포 스케일에 일관된 단위(rem 또는 px 하나로 통일)와 명시적 행간(line-height) 토큰을 둔다(토스: 16px 본문/행간24px = 1.5배수)
- [ ] 버튼형 선택지(카카오톡 관성)를 채택하되, 포커스 이동·스크린리더 안내·상태 피드백 같은 마이크로 디테일까지 설계한다(토스 사례)
- [ ] AI 캐릭터/마스코트를 쓰더라도 정보 구조는 타이포+컬러+여백만으로 완결시키고, 캐릭터는 톤 보조 요소로 국한한다(채널톡의 "눈→입" 전환, SKT 에이닷의 캐릭터 축소 궤적이 시사하는 방향)
- [ ] 신뢰 신호는 공식 인증 배지·보안 문구보다 "절제된 카피 + 여백 + 일관된 컬러"로 암묵적으로 전달하는 편이 국내 세련된 서비스들의 공통 패턴(과잉 인증마크 나열은 오히려 관공서 톤)

### 촌스러움을 만드는 요소
- [ ] 웹폰트를 지정하지 않고 OS 기본 서체에 의존(위택스봇 실증: CSS 412줄에 `font-family` 선언 0건)
- [ ] 상호 무관한 색상 3개 이상을 한 화면에 공존시킴(위택스봇 실증: 파랑·청록·보라·바이올렛·초록·주황 등 8색 난립)
- [ ] border-radius가 2/5/10/15/17/18px 등 스케일 없이 산발적 — "그때그때 개발자가 임의로 정한" 흔적이 그대로 남음
- [ ] 라디오버튼·체크박스 등 폼 컨트롤을 CSS 대신 PNG 배경 이미지로 구현(레티나에서 흐릿함)
- [ ] 롤링배너·캐러셀 라이브러리(slick.js 등)를 상담/챗봇 화면에까지 끌어옴 — "안내창구"가 아니라 "홍보판" 관성
- [ ] rem과 px를 같은 파일 안에서 무원칙하게 혼용(단위 체계 붕괴의 증거)
- [ ] 마스코트를 대국민 공모·다수결로 결정 — 심사 절차의 산물이라 특정 톤을 관통하기 어렵고, 결과적으로 "무난하지만 개성 없는" 캐릭터가 되기 쉬움
- [ ] 기관/서비스마다 로고·아이콘 위치·검색 UI가 제각각이라 사용자가 매번 새로 학습해야 함(거버넌스 부재가 시각적 비일관성으로 드러난 사례 — KRDS 도입 배경 자체가 이 문제의 방증)
- [ ] 오래된 라이브러리(jQuery 3.1.1급)를 그대로 얹어 인터랙션이 버벅이거나 트랜지션이 끊기는 인상을 줌
