# blessing-reboot 2026-08-06 — 클라이언트 랜딩+채팅 리부트 6안

유지한 것은 셋뿐: ① 문서기반 챗봇(인용이 있는 답변)이라는 정체성 ② 보라 계열 참고 ③ 엠블럼 로고.

- 열어보기: `compare.html` (6안 전환·랜딩/채팅 토글·2면 비교) 또는 각 HTML 단독 오픈
- 각 파일은 빌드 없이 열리는 self-contained. 랜딩 ↔ 채팅은 파일 내 전환(`#chat`)
- 데스크톱 우선(1440) + 모바일(390) 대응. `_diag.html?f=ui-a&v=chat` 로 390px 확인
- 스크린샷: `_shots/` (1440 랜딩·채팅 12장)

## 6안 요약

| 파일 | 방향 | 스킬 | 한 줄 컨셉 |
|---|---|---|---|
| `ui-a` | A 서재 | ui-ux-pro-max | 크림 캔버스 + 고운바탕 세리프. 랜딩에 **책등 서가**, 답변은 각주+발췌 팝업+형광펜 카드 |
| `ui-b` | C 근거 | ui-ux-pro-max | 대형 타이포 미니멀("근거 없이 답하지 않습니다"). 채팅은 **3단: 검색 타임라인 + 원문 패널(Cited/Found 분리)** |
| `fd-a` | B 창구 | frontend-design | 밝은 행정지 모노크롬. **답변이 '회신 공문' 양식**(문서번호·붙임·근거확인 관인). 랜딩에 "답하는 것/답하지 않는 것" 안내판 |
| `fd-b` | A 서재 | frontend-design | **저녁 서재**: 짙은 가지빛 방 + 램프빛 종이 답장 + Hahmlet 세리프 + **갈피끈** 시그니처. "밤늦게 물어도, 책은 펼쳐져 있습니다" |
| `ts-a` | C 근거 | taste-skill | **마지널리아 지면**: 본문 왼쪽, 근거가 문장 옆 여백에 정렬. 랜딩 히어로가 실제 답변 지면의 축소 표본 |
| `ts-b` | B 창구 | taste-skill | 다크 뉴트럴 절제 시스템(Linear 계열 번안). 보라는 인터랙티브 상태에만. "문서가 말하는 만큼만, 정확하게" |

같은 방향을 서로 다른 스킬 2개가 해석: A=ui-a/fd-b · B=fd-a/ts-b · C=ui-b/ts-a.

## 전 시안 공통 규칙 (조사 근거)

- AI 응답은 전폭 문서, 말풍선은 사용자 발화에만 (Perplexity 계열 실증)
- 주조색 = 보라 1색 + 뉴트럴, 그라디언트·글로·이모지·스파클·로봇 아바타 0 (안티슬롭 블랙리스트)
- 신뢰도 % 미노출, 문서 배지에 신호등 색 금지, 인용 카드에 판본·조항 표기 (12제품 조사 공통)
- "근거 없음"을 답변 차단이 아니라 **정직한 안내**로 표현 (범위 밖 안내 블록)
- 한글: Pretendard 명시 로드 + `word-break: keep-all`, radius 단일 스케일, SVG 아이콘만
- `prefers-reduced-motion` 대응, 포커스 링, 터치 타깃 확보

## 기술 메모

- 뷰 전환은 `.view.on` 단일 규칙. **스크림 div는 기본 `display:none`** (아니면 데스크톱 그리드의 아이템으로 잡혀 레이아웃이 밀림 — 이번 라운드에서 실제로 밟은 버그)
- 웹폰트는 전부 무료 임베딩 라이선스: Pretendard(jsdelivr), Gowun Batang·Hahmlet·IBM Plex Mono·JetBrains Mono(Google Fonts)
- 콘텐츠(문서명·조항·인용문)는 목데이터. 실제 규정 원문이 아님
