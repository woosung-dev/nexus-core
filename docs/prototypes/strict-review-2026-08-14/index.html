  1. 사례 1~2 는 과잉 거절인가? 규정집이 답을 갖고 있는 문항인데 strict 가 막았다. 막힌 답변을 읽고 「이 정도면 나가도 됐다」인지 「근거 없이 단정했으니 막는 게 맞다」인지 판단해라. 이것 하나가 strict 를 켤지 말지를 가른다.
    보는 법: 「주입한 근거」를 펼쳐 원문을 읽고, 답변 내용이 그 원문에서 나왔는지 대조해라. 나왔는데 막혔다면 게이트가 근거가 아니라 표기 습관을 재고 있는 것이다 — 어휘 게이트는 답변에 [reg-53] 이나 제53조 가 있는지를 보고, 의미 게이트는 구글이 인용을 붙였는지만 본다. 잣대가 서로 다르다.
  2. 사례 3~ 은 막는 게 맞나? 정답지와 규정집이 어긋나는 자리다. legacy 는 0% 막고 전부 답했다. 여기서 막는 것이 우리가 원하던 동작인지 확인해라.
  3. 어휘검색과 의미검색 중 무엇을 1차로 갈 것인가? 같은 PDF 2종을 보는데 의미검색은 81.8% 답하고 어휘검색+strict 는 45.5% 답한다. 「많이 답하되 위험한 자리를 못 막는 봇」과 「적게 답하되 막는 봇」의 선택이다. 의미검색은 strict 를 켜도 유보가 +0.9p 밖에 안 는다.
