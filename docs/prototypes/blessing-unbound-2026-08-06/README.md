## 전 시안 공통 규칙 (조사 근거)

- 답변 전폭 문서·말풍선은 사용자만 / 신뢰도 % 미노출 / 문서 라벨 신호등 색 금지 / 인용에 판본·조항·쪽수
- 근거 없음 = 차단이 아니라 정직한 안내 / 하단 고지 "최종 확인은 소속 교회를 통해"
- 한글: `word-break:keep-all` 전역, `line-height` 명시(내장 1.193 함정), 자간 하한 -0.03em(한글 여백이
  라틴의 60%), 헤드라인 수동 개행(`white-space:pre-wrap`) 6~12자/줄, 해요체 통일+미완결 종결 헤드라인
- 프리미엄 실측 규칙: 본문에 순검정 금지, 액센트 면적 1% 이하, radius 3값, 보더 1px 잉크-alpha,
  모션 150~180ms ease-out, 노이즈 0, `prefers-reduced-motion` 대응
- em-dash(—) 0 (본문·라벨·각주 전부), 가운뎃점은 줄당 1회 이내(taste 파일 엄격 적용)
- 스크림 div 기본 `display:none` (reboot 라운드에서 실제로 밟은 레이아웃 버그)

## QA에서 잡은 결함 (재발 주의)

- **`nav.g a`(0,1,2)가 `.btn-*`(0,1,0)보다 특이도가 높아 헤더 CTA 글자색이 덮임** → 전 파일에
  `nav.g a.btn-*` 명시 규칙 추가로 수정. 내비 안에 버튼 클래스를 넣을 때 반복되는 함정.
- 폰트 CDN: 마루부리는 네이버 공식(`hangeul.pstatic.net`), SUIT·Wanted Sans·Pretendard는 jsDelivr,
  Hahmlet은 Google Fonts. IBM Plex Mono는 **한글 글리프가 없어** 라틴 메타 전용(JetBrains Mono 동일).
