# 공용 목데이터 콘텐츠 팩 — blessing-unbound-2026-08-06

6안이 전부 같은 콘텐츠를 쓴다. 축이 달라도 데이터가 같아야 대조가 성립한다.
봇 이름·문서명·규정 내용·인용문은 전부 UI 검토용 예시다. 실제 규정 원문이 아니다.

## 서비스 정체 (계승 항목 단 둘)

1. **RAG(문서)기반 챗봇** — 승인 문서를 근거로 답하고, 근거를 인용으로 보여준다
2. **멀티봇** — 담당 문서가 다른 여러 창구(봇)가 있다

서비스명은 "블레싱" 기본. 워드마크·표기(한/영)는 안별 재량.

## 채팅 목대화 1벌 (전 시안 공통)

**사용자**: 축복식 준비 절차가 궁금해요. 어디서부터 시작해야 하나요?

**답변** (전폭 문서형):
> 축복식 준비는 소속 가정 교회를 통한 후보자 등록에서 시작합니다.[1]
>
> 1. **소속 교회와 상의** — 축복을 희망하는 가정은 먼저 소속 교회와 상의합니다.[1]
> 2. **후보자 등록** — 축복 후보자는 소속 교회의 추천을 받아 정해진 기간 안에 등록합니다.[1]
> 3. **준비 교육 이수** — 축복식에 앞서 소정의 준비 교육을 이수합니다.[2]
> 4. **정성 기간** — 축복식에 앞서 각 가정은 정해진 기간의 정성을 준비합니다.[3]
>
> 서류 목록은 교구마다 안내 시기가 달라, 소속 교회 담당자에게 확인하시는 것이 가장 정확합니다.

**인용**:
- [1] 축복 안내서(2026 정본) · 4장 2절 — "축복을 희망하는 가정은 먼저 소속 교회와 상의한다. 축복 후보자는 소속 교회의 추천을 받아 정해진 기간 안에 등록한다."
- [2] 축복식 준비 지침 · 2장 — "축복식에 앞서 소정의 준비 교육을 이수한다."
- [3] 축복식 준비 지침 · 3장 — "축복식에 앞서 각 가정은 정해진 기간의 정성을 준비한다."

**후속 질문 칩**: "후보자 등록 서류가 궁금해요" · "준비 교육 일정은 어디서 보나요" · "정성 기간은 얼마나 되나요"

**근거 없음 표본** (두 번째 턴, 선택 사용):
사용자: "제 경우엔 언제 등록하는 게 좋을까요?"
답변: 등록 시기의 개인별 판단은 제가 가진 문서에 나와 있지 않습니다. 소속 교회 담당자와
상의하시길 권합니다. 일반 절차는 위 안내와 같습니다. — (인용 0건 = 검색은 했으나 근거 없음을
정직하게 안내. 차단·에러 톤 금지)
