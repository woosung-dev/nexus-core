## 1. 레이아웃 골격 유형학

### ① 중앙 축 타이포 히어로 + 플로팅 카드 스트립
- **사례**: [Mainframe](https://mainframe.app) — dark.design 수록 (https://www.dark.design/site/mainframe-1780069525324)
- 거의 검정 배경 + 히어로 중앙에만 은은한 웜 라디얼 글로우. 초대형 중앙정렬 헤드라인("Watch your agents work.") + 알약형 화이트 CTA 버튼 하나. 그 아래로 3개의 비디오 프리뷰 카드가 뷰포트 하단에 살짝 걸치듯 떠 있음(카드 상단은 반투명 페이드로 처리해 "더 있음"을 암시).
- 스크린샷 직접 확인함.

### ② 좌우 비대칭 스플릿 (텍스트 vs 3D 오브제)
- **사례**: [Khroma](https://khroma.co) — dark.design 수록 (https://www.dark.design/site/khroma-1778329715936)
- 좌측 40%는 짙은 배경 위 텍스트 컬럼(헤드라인+설명+CTA), 우측 60%는 풀블리드로 채운 단일 3D 글래스모픽 오브제(무지개 굴절이 배경으로 번짐). 텍스트와 이미지 영역이 정확히 나뉘는 게 아니라 오브제가 카드 프레임 자체처럼 화면 우측을 압도.
- 스크린샷 직접 확인함.

### ③ 풀블리드 컬러블록 + 마퀴 티커
- **사례**: [Rig](https://rig.ai) — dark.design 수록 (https://www.dark.design/site/rig-1780069209561), Awwwards에도 "Rig AI"로 등재 (https://www.awwwards.com/sites/rig-ai)
- 히어로 전체를 단일 채도 높은 오렌지-레드로 풀블리드 처리(그라디언트 아님, 플랫 컬러). 초대형 컨덴스드 그로테스크 블랙 타이포가 배경을 거의 다 채움. 히어로 하단이 검정 마퀴 티커 바("NATIVE INFERENCE · 100% OFFLINE · YOUR HARDWARE, YOUR RULES...")로 다음 섹션(검정 배경)과 연결됨.
- 스크린샷 직접 확인함.

### ④ 에디토리얼 스캐터 콜라주
- **사례**: dark.design "Ponder" 항목 (https://www.dark.design/site/ponder-1782376605237) — 스크린샷은 실제로는 영상편집 AI 툴로 보이는 화면("Video Editing, Reinvented")이라 브랜드명이 카탈로그와 다를 수 있음, 패턴 자체는 신뢰도 높음.
- 검정 배경, 중앙에 심플한 화이트 헤드라인+CTA 2개. 그 주위로 크기와 위치가 제각각인 사진 타일 6~7개가 그리드에 정렬되지 않고 "흩뿌려진" 것처럼 배치됨 — 벤토(균일 격자)와 달리 비정형·비대칭 배치가 핵심.
- 스크린샷 직접 확인함.

### ⑤ 엔터프라이즈 허브 다이어그램 히어로
- **사례**: [Clarasight – The AI Platform for Enterprise Travel & Expense](https://land-book.com/websites/98078-clarasight-the-ai-platform-for-enterprise-travel-and-expense)
- 히어로 상단은 딥 인디고→화이트 수직 그라디언트("지붕"으로만 사용, 전체 배경 아님), 중앙정렬 헤드라인+CTA, 그 아래 고객사 로고 마퀴("Trusted by..."), 이어서 중앙 브랜드 마크를 둘러싸고 미니 앱 스크린샷 카드들이 궤도(orbit)처럼 배치된 다이어그램 — 여러 데이터/기능이 하나의 허브로 모인다는 서사를 시각화.
- 스크린샷 직접 확인함.

### ⑥ 벤토 그리드 (참고, 시각 미확인)
- Pinterest 검색결과(SaaS landing page minimal)에 반복 등장: "feature cards for integrations, automation, security... followed by workflow steps, pricing plans" 식의 3~4열 벤토형 피처 그리드가 SaaS AI 랜딩의 기본값으로 매우 흔함. Awwwards AI 카테고리에도 다수(Grassfeld, Senthora, Voxelo AI 등).
- 트렌드 기사에 따르면 2026년형 벤토는 "액티브 그리드"로 진화 — 정적 카드가 아니라 호버 시 타일이 확장되거나 비디오가 재생됨.

### ⑦ 대시보드 프리뷰 목업 히어로 (참고, 시각 미확인)
- Pinterest에서 "AI app landing page 2025" 검색 시 가장 빈번한 패턴: 다크 네이비 배경 위에 애널리틱스 대시보드 + AI 챗 프리뷰 창을 겹쳐 배치한 히어로 목업. "Modern AI startup landing page with a dark blue interface, analytics dashboard, AI assistant chat" 식 설명이 다수 반복됨.

## 2. 타이포그래피 경향

- **오버사이즈 컨덴스드 그로테스크**: Rig처럼 뷰포트 폭을 거의 다 채우는 초대형 블랙 웨이트 헤드라인이 AI 툴 랜딩의 표준 스케일이 됨.
- **세리프는 "포인트 워드"로 부활**: Khroma의 헤드라인 "Design with *colors you love.*"처럼 문장 전체를 세리프로 바꾸지 않고, 감성적 핵심 단어 한두 개만 세리프 이탤릭으로 강조하는 절충형이 눈에 띔. 완전한 세리프 전환보다 "산세리프 본문 + 세리프 악센트"가 더 흔함.
- **모노스페이스/트래킹 확장 라벨**: Rig의 티커 바("NATIVE INFERENCE · 100% OFFLINE")처럼 대문자+자간 확장된 모노 스타일 라벨이 "기술적 정밀함"의 기표로 쓰임.
- **키네틱 타이포그래피 + 가변 폰트**: 트렌드 기사 공통 언급 — 스크롤/호버에 반응해 늘어나거나 커서를 따라가는 헤드라인, 무거운 웹폰트 여러 벌 대신 가변 폰트 하나로 스타일 커버(성능 이점도 강조됨). ([writerdock.in](https://writerdock.in/blog/bento-grids-and-beyond-7-ui-trends-dominating-web-design-2026), [studiomeyer.io](https://studiomeyer.io/en/blog/webdesign-trends-2026))

## 3. 컬러 월드 경향

### 신선한 팔레트
- **플랫 단일 포화색 풀블리드** (Rig의 오렌지-레드): 그라디언트를 아예 배제하고 브랜드 컬러 하나를 강하게 미는 방식. 그라디언트 남용에 대한 반작용으로 읽힘.
- **거의 검정 + 단일 웜 액센트 글로우** (Mainframe): 배경은 순수 블랙에 가깝고, 포인트는 은은한 호박색/웜톤 라디얼 글로우 하나뿐 — 채도 절제.
- **그라디언트는 "지붕"으로만, 배경 전체 도배 금지** (Clarasight): 인디고 그라디언트를 히어로 최상단에만 얇게 쓰고 스크롤하면 바로 화이트로 전환 — 그라디언트 자체가 문제가 아니라 "전면 도배"가 문제라는 시사점.
- **소프트 브루탈리즘 파스텔**: 트렌드 기사에서 공통 언급 — 세이지그린, 버터옐로 같은 파스텔에 굵은 테두리를 더해 "차분하지만 무르지 않은" 톤. 다크모드도 "기본값"으로 확산 중(OLED 절전 + 브랜드 정체성).

### 이미 식상해진 팔레트 (AI-slop 판정)
- **중앙 배치 히어로 뒤 보라색 그라디언트 오브(orb/blob) + Inter 폰트 + 알약형 배지 + 3열 아이콘 카드** 조합이 "AI가 생성한 티가 나는" 표준 시그니처로 이미 문서화됨. Tailwind UI가 5년 전 모든 버튼을 `bg-indigo-500`으로 기본 설정한 것이 LLM 학습 데이터에 누적되며 "AI가 만들면 보라색"이라는 밈이 된 배경까지 기사에서 다뤄짐. ([saascity.io](https://saascity.io/blog/stunning-frontend-designs-vibe-coding-avoid-ai-slop), [vibecodekit.dev](https://vibecodekit.dev/ai-slop-design), [medium.com/@creativeaininja](https://medium.com/@creativeaininja/your-ai-keeps-building-the-same-purple-landing-page-taste-skill-fixes-that-e76ab584679b), [prg.sh](https://prg.sh/ramblings/Why-Your-AI-Keeps-Building-the-Same-Purple-Gradient-Website))
- 얇은 회색 테두리+연한 그림자의 둥근 카드 3개, 중앙정렬 헤드라인+배지 조합 자체도 "가장 흔한 평균치"로 지목됨 — 이미 회사 내부적으로도 blessing-reboot 조사(2026-08-06)에서 동일하게 "보라 그라디언트=AI-slop"으로 판정된 바 있어 이번 조사와 결론이 일치함.

## 4. 모션·인터랙션 경향 (과하지 않은 것 위주)

- **벤토 그리드 2.0**: 정적 카드가 아니라 호버 시 타일이 슬라이드로 확장되거나 짧은 비디오가 재생됨 — 정보 밀도를 유지하면서 클릭 전에 미리보기를 주는 절제된 방식.
- **마퀴/티커 스트립**: Rig처럼 무한 스크롤되는 텍스트 한 줄이 섹션 전환부에 들어가는 것만으로도 저비용·고임팩트 모션이 됨(3D나 파티클보다 훨씬 가벼움).
- **스크롤 타임라인 기반 내러티브**: CSS `scroll-timeline` API로 스크롤 위치에 맞춰 배경/레이어가 전환되는 방식이 다수 언급됨. 모바일에서는 무거운 패럴랙스를 피하라는 경고도 함께 나옴.
- **마이크로 딜라이트**: 완료 액션에 컨페티, 좋아요 버튼 펄스처럼 "필수는 아니지만 있으면 기분 좋은" 초소형 애니메이션 — 과하지 않게 쓰라는 게 공통된 톤.
- **패럴랙스 3.0**: 배경은 천천히 흐르고 전경 요소는 스크롤 스냅으로 고정되는 물리 기반 방식 — 90년대식 배경-전경 속도차 패럴랙스보다 절제됨.

## 5. 안티패턴 — "AI가 만든 템플릿"으로 바로 읽히는 것

1. 중앙정렬 히어로 뒤 **보라/핑크 그라디언트 오브** + Inter/Roboto 폰트 조합
2. 헤드라인 위 **알약형(pill) 배지** ("✨ New" 류) — 특히 보라 배지
3. 아이콘 위 + 제목 + 1문장 설명으로 구성된 **3열(또는 4열) 균일 카드 그리드**를 피처 섹션에 기계적으로 반복
4. 그림자 얇고 테두리 연한 **둥근 모서리 카드**가 페이지 전체를 도배
5. 2024년 유행했던 벤토 그리드를 **호버 인터랙션 없이 정적 이미지로만** 모방 — 이제는 클리셰로 읽힘
6. 3D/히어로 영상 등 **무거운 에셋으로 인한 느린 로딩** — "기술 피로"로 이탈 유발한다고 여러 기사가 공통 경고

## 6. 접속 실패/제한된 소스

- **Pinterest 개별 핀 이미지**: 로그인 월 때문에 이미지 직접 열람 불가. 검색결과 페이지의 캡션/설명 텍스트에서만 경향 추출(위 ⑥⑦ 항목 근거).
- **awwwards.com/websites/ai/**: 사이트 카드 목록 자체는 텍스트로 확보했으나(수상작명 다수 확보), 개별 수상작 상세 페이지 시각 검토는 하지 않음(시간 제약).
- **godly.website**: `?query=` 파라미터가 실제로 필터링되지 않아(전체 최신 피드만 반환) AI/챗봇 특화 자료를 걸러내지 못함 — 참고 가치 낮음, 최종 자료에서 제외.
- **minimal.gallery 스크린샷 직접 다운로드**: 샌드박스에서 `minimal.gallery` 도메인에 대한 직접 DNS 해석이 차단되어 이미지 원본을 받지 못함(Jina Reader 경유 텍스트/목록만 확보 — Wist: AI Live Chat, Letta, Ploy, Future AGI 등 실제 사이트명은 확보함).
- **land-book.com CDN 이미지**: 최초 1회(Clarasight)는 성공했으나 이후 요청은 403(레이트리밋 추정)으로 실패 — Taste Labs 등 추가 스크린샷은 확보하지 못함.
- **landing.love/categories/ai/**: 페이지 접속은 되었으나 실제 사이트 카드가 JS로 렌더링되어 텍스트 추출 시 카테고리 내비게이션만 나오고 개별 사례는 확보하지 못함.

## 7. 문서기반 멀티봇 챗봇 랜딩+채팅 화면에 적용할 무드 방향 후보 6개

서로 확실히 다른 방향으로 구성 (다크/라이트, 세리프/산세리프, 플랫컬러/그라디언트, 정적/모션 각각 분산).

1. **모노리스 다크** — 골격: 중앙 축 타이포 히어로 + 하단에 살짝 걸친 채팅 프리뷰 카드(Mainframe식) / 컬러: 거의 블랙 배경 + 단일 웜 라디얼 글로우 하나 / 타이포: 오버사이즈 지오메트릭 산세리프 헤드라인 + 모노스페이스 라벨.
2. **에디토리얼 세리프** — 골격: 좌우 에디토리얼 컬럼(좌 설명 텍스트, 우 인용/자료 스니펫 카드) / 컬러: 웜 오프화이트 + 잉크 네이비, 그라디언트 없음 / 타이포: 산세리프 본문에 헤드라인 포인트 단어만 세리프 이탤릭(Khroma식 절충).
3. **솔리드 블록 컬러** — 골격: 풀블리드 단일 채도 컬러 히어로 + 하단 마퀴 티커(핵심 가치 키워드 스크롤) / 컬러: 보라 대신 테라코타나 세이지그린 등 비클리셰 단일 포화색 / 타이포: 컨덴스드 블랙 그로테스크(Rig식) — 봇마다 다른 색 배지로 구분하기 쉬움.
4. **허브 다이어그램 라이트** — 골격: 밝은 인디고→화이트 그라디언트는 히어로 상단 "지붕"에만, 로고/출처 마퀴 아래 중앙 브랜드를 둘러싼 오빗형 봇 아이콘 클러스터(Clarasight식) / 컬러: 라이트 인디고+화이트 / 타이포: 클린 지오메트릭 산세리프 — 멀티봇 구조를 다이어그램으로 직관적으로 설명.
5. **스캐터 콜라주 웜** — 골격: 비대칭 스캐터 그리드(자료/문서 조각 카드가 흩어진 콜라주) / 컬러: 딥 블랙 배경 + 세피아톤 이미지 조각 / 타이포: 심플 화이트 산세리프 중앙 헤드라인 + 소문자 모노 캡션 — 아카이브·기록물 같은 정서로 "문서 기반"을 체감시킴.
6. **소프트 브루탈 파스텔 벤토** — 골격: 액티브 벤토 그리드(호버 시 확장되는 타일, 타일 하나 = 봇 하나) / 컬러: 세이지그린·버터옐로 파스텔 + 굵은 블랙 테두리(소프트 브루탈리즘) / 타이포: 굵은 산세리프 헤드라인 + 얇은 산세리프 바디 대비 — 친근하고 접근성 높은 톤, 여러 봇을 타일로 명확히 구분.
