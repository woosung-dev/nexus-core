## 1. character.ai — 글로벌 1위

출처: https://character.ai (2026-08-06 실접속, 비로그인)

1. **첫 화면 구조**: 비로그인 방문자에게 봇 그리드가 전혀 노출되지 않는다. 화면 전체가 **회원가입 유도 카드 하나**다 — "천만 개 이상의 캐릭터를 이용하세요 / 10초 만에 가입하기" + Google/Apple/이메일 버튼 3개. 스크롤해도 아래에 푸터(정보·채용·보안센터·블로그·쿠키정책 등) 링크만 있을 뿐 콘텐츠가 없다. 즉 **완전 로그인 게이트**형 랜딩. (같은 날 앞선 세션이 캡처한 `cai-home.png`에서는 우측에 화성 궤도를 보는 우주비행사 이미지가 있었으나, 이번 접속에서는 해당 히어로 이미지가 아예 로드되지 않고 빈 배경만 남음 — 이미지가 있을 때도 텍스트 카드가 화면을 지배하는 구조는 동일)
2. **봇 카드 디자인**: 확인 불가 (로그인 게이트로 카드 자체가 노출되지 않음). 다만 브랜드 톤은 확인됨 — 순검정 텍스트, 옅은 회색(#f2f2f0 근사) 배경, 버튼은 순검정 필(pill)형.
3. **온보딩 진입**: 방문 즉시(0클릭)로 가입 카드가 뜨고, Google/Apple 원클릭 소셜 로그인을 최상단에 배치. "10초 만에 가입하기"라는 카피로 가입 마찰을 정면으로 축소 어필. 콘텐츠를 먼저 보여주고 나중에 가입시키는 방식이 아니라 **가입이 곧 입장권**.
4. **타이포·컬러**: 라이트 테마, 무채색(블랙/오프화이트) 중심, 브랜드 컬러가 거의 없음 — 캐릭터 아트(이미지)가 유일한 색채 요소. 한글 폰트는 시스템 산세리프로 보임(별도 웹폰트 확인 안 됨, 브라우저 콘솔 접근 전 페이지 이탈).
5. **세련 vs slop**: 절제된 편. 카피 1줄 + 버튼 3개뿐인 극단적 미니멀리즘은 "여기는 커뮤니티/제품이 이미 검증됐다"는 자신감의 표현으로 읽힌다(천만 개 캐릭터라는 숫자가 그 자신감의 근거). 다만 **첫 방문자에게 아무 실물(캐릭터가 뭘 하는지)도 안 보여주고 가입부터 요구**하는 건 냉정하게는 전환율에 유리할 수 있어도 "둘러보기" 경험을 완전히 포기한 선택 — 브랜드 신뢰가 없는 신규 서비스가 그대로 베끼면 이탈만 부른다.

## 2. 크랙 (crack.wrtn.ai) — wrtn, 한국

출처: https://crack.wrtn.ai (2026-08-06 실접속, 비로그인) + 기존 캡처 `crack-home.png`

1. **첫 화면 구조**: 로그인 없이 즉시 전체 콘텐츠 그리드가 열린다(캐릭터.ai와 정반대). 상단 GNB(스토리/캐릭터/내 작품/이미지) → 카테고리 필터 탭(추천/신규 랭킹/전체 랭킹/오늘 신작/남성 인기/시뮬레이션/로맨스/GL/1:1 롤플레잉/SF·판타지…) → 대형 캐러셀 배너(스토리 추천, 이벤트) → "신규 사용자 대박 혜택"(재화 지급) 배너 → "오직 크랙에서만" 오리지널 섹션 → "QWER 콜라보"처럼 **IP 콜라보 섹션** → "공식 대표 작품" → "떠오르는 신예 창작자들" → "공식 크리에이터들의 뜨거운 신작"… 식으로 **홈쇼핑/웹툰 플랫폼처럼 다수의 큐레이션 레일(가로 스크롤 랙)** 이 세로로 계속 이어진다.
2. **온보딩 진입**: 첫 방문 시 **모달로 취향 온보딩**을 먼저 받는다 — "어떤 콘텐츠를 추천해드릴까요? (가입 없이 바로 추천받을 수 있어요)" + 남성향/여성향/전체 3개 아바타 카드 선택 + SKIP 가능. 로그인 없이도 개인화를 걸어주는 구조.
3. **봇/캐릭터 카드 디자인**: 스토리 탭은 세로형 표지 이미지 카드(웹툰/웹소설 표지처럼 텍스트·타이틀이 이미지에 합성). 캐릭터 탭은 별도 카드 스타일 — **세로 3:4 인물 일러스트 이미지 + 상단 좌측에 대화수 배지(예: 49.6K, 툭 튀어나온 말풍선 아이콘)** + 이미지 아래 흰 여백에 이름(볼드)·짧은 소개문(1~2줄)·제작자 @핸들. 그리드 4~5열, 카드 간 간격 좁음, 모서리는 살짝 둥긂(약 8px), 그림자 없음(플랫). 캐릭터 카드는 라이트 테마(흰 배경) 위에 이미지 카드가 얹힌 형태.
4. **타이포·컬러**: 라이트 테마 기본. `font-family: Pretendard, "Apple SD Gothic Neo", system-ui, sans-serif` (JS computed style로 확인). 포인트 컬러는 코랄/레드(브랜드 로고, CTA 버튼, 배지)와 노란색(이벤트 배너)을 섞어 씀 — 채도 높은 캐주얼 톤.
5. **세련 vs slop**: 정보 밀도가 매우 높고 레일이 끝없이 이어지는 구조는 "웹소설/웹툰 플랫폼"의 문법을 그대로 가져온 것 — 캐릭터 챗봇이라기보다 콘텐츠 커머스에 가깝다. 세련됐다고 보기보다는 **전환·리텐션에 최적화된 실용주의**에 가깝다. 배지·랭킹·신작·콜라보 태그가 카드마다 겹겹이 붙어 다소 산만(대화수 배지 + N뱃지 + 랭킹 리본이 한 카드에 동시에 뜨는 경우도 있음) — 이 밀도는 "세련"보다는 "장사가 잘 되는 진열대"에 가깝고, 브랜드가 절제를 원한다면 배지 종류를 줄여야 함.

## 3. 제타 (zeta-ai.io) — 스캐터랩, 한국

출처: https://zeta-ai.io/ko (2026-08-06 실접속, 비로그인)

1. **첫 화면 구조**: 데스크톱 브라우저로 접속해도 **화면 폭을 강제로 모바일 앱 폭(약 980px)으로 좁혀 중앙 정렬**하고 나머지는 순검정 여백으로 채운다 — 반응형 데스크톱 레이아웃을 아예 설계하지 않고 "모바일 웹앱을 데스크톱에 그대로 띄운" 방식. 화면 최하단에는 **네이티브 앱처럼 하단 탭바(홈/대화/만들기/마이페이지)** 가 고정되어 있어, 웹인데도 앱 경험을 그대로 재현.
2. **진입 순서**: 접속 즉시 콘텐츠 그리드가 배경에 깔린 채, "zeta를 즐기기 전에 확인할 내용이 있어요" **필수 동의 모달**(민감정보 미입력 안내, 비윤리적 이용 금지, 개인정보 수집 동의)이 뜬다 — 스킵 불가, "동의하기" 버튼 하나만 존재. 콘텐츠는 로그인 없이 바로 열람 가능.
3. **봇 카드 디자인**: 2열 그리드의 세로형 카드. 카드 자체가 "이미지 + 그 위에 얹힌 텍스트"가 아니라, **이미지 안에서 하단 그라데이션 스크림 위에 제목·설명·해시태그가 오버레이**되는 방식(크랙의 화이트 카드 하단 텍스트와 다름). 카드 우상단에는 보라색 리본형 "콘테스트" 배지가 대각선으로 붙고, 좌상단에는 대화수(예: 3.8만)와 N(신규) 배지. 모서리 둥긂 큼직(12~16px), 카드 이미지가 반실사풍 일러스트(로맨스/츤데레/뱀파이어/오메가버스 등 자극적 로그라인이 카피에 그대로 노출 — "남편의 내연녀가 되었다" 류).
4. **타이포·컬러**: 다크 테마(배경 `rgb(21,21,22)`, 텍스트 흰색). `font-family: "Pretendard Variable", ... "Noto Sans KR", "Malgun Gothic", sans-serif` (JS computed style로 확인 — Pretendard Variable을 명시적으로 최우선 지정). 포인트 컬러는 선명한 보라/바이올렛(로그인 버튼, 리본 배지, 활성 탭 인디케이터).
5. **세련 vs slop**: 다크 + 보라 + 웹소설풍 자극적 카피의 조합이라 "세련"보다는 "정욕/자극 소비 콘텐츠 플랫폼" 톤이 강하다. 다만 **모바일 웹을 데스크톱에서도 그대로 유지하는 결정은 제품 판단으로선 합리적**(어차피 유저 대부분이 모바일에서 씀 — 데스크톱 대응에 리소스를 안 쓴 것) — 브랜드가 "웹에서도 진지하게 쓰는 도구"로 보이고 싶다면 이 패턴은 피해야 한다. 카드 위 텍스트 오버레이가 이미지에 따라 가독성이 들쭉날쭉(밝은 배경 이미지 위 흰 글씨가 묻히는 카드 존재) — 대비 관리가 허술한 지점.

## 4. Talkie (talkie-ai.com)

출처: https://www.talkie-ai.com/ko (2026-08-06 실접속, 비로그인)

1. **첫 화면 구조**: 데스크톱 전용 사이드바 레이아웃(Notion/Discord류) — 좌측 고정 아이콘+라벨 내비(Talkie 만들기/이미지 생성/발견/검색/커뮤니티/메모리/Talkie Claw), 상단 검색바 + 앱 다운로드 버튼. 메인 영역 히어로는 "Are you… Looking for connections?" 카피 + **카드가 부채꼴로 겹쳐 쌓인(스택/팬 형태) 캐릭터 미리보기 비주얼**, 좌우 화살표로 넘김. 그 아래 성별 필터(모두/남성/여성/논바이너리) → 카테고리 탭(Recommend/Featured/Play&Fun/Helper/Original/Anime&Game/Fiction&Media/Icon/School/Fantasy/Sci-Fi) → 7열 밀집 그리드.
2. **온보딩 진입**: 쿠키 동의 배너 이후, 스크롤/체류 중 **대명사(그녀/그/그들)·연령대(0-13~26+) 선택을 요구하는 강제 모달**이 별도로 뜬다(닫기 버튼 없음, Esc로도 안 닫힘) — 콘텐츠 접근 자체를 막지는 않지만 계속 화면에 남아 있어 사실상 응답을 유도. 크랙의 "취향 온보딩(스킵 가능)"보다 훨씬 완강한 형태.
3. **봇 카드 디자인**: 정사각형에 가까운 카드, 이미지 스타일이 **애니메이션풍과 실사(포토리얼) 인물이 한 그리드에 섞여** 있음(양산형 캐릭터.ai 클론과 달리 실사 인물 페르소나 비중이 높다 — 로맨스/친구/썸 계열). 카드 좌하단 눈 아이콘+조회수, 이름, 1줄 소개(말줄임). 일부 카드에 "LIVE" 배지(실시간 방송 중인 페르소나 컨셉). 카드 간격 매우 좁고(거의 붙음) 모서리 둥긂 작음, 그림자 없음.
4. **타이포·컬러**: 다크 테마(순검정 배경). `font-family`는 **커스텀 한글 웹폰트를 지정하지 않고 시스템 폰트 스택(-apple-system, Segoe UI, Roboto…)에만 의존** — 한국어 서비스인 크랙·제타와 달리 로컬라이제이션 타이포 투자가 없다는 뜻. 포인트 컬러는 옅은 보라/라벤더 그라데이션 텍스트(히어로 타이틀), 나머지는 무채색.
5. **세련 vs slop**: 사이드바+카드스택 히어로는 셋 중 가장 "SaaS 프로덕트"스러운 느낌(각진 대시보드 톤)이라 캐릭터 챗봇치고는 차분하다. 그러나 **7열까지 욱여넣은 밀집 그리드**는 이미지가 작아 캐릭터 얼굴 디테일이 안 보이고, 실사/애니메이션 화풍이 뒤섞여 시각적 통일감이 떨어진다 — "화풍 큐레이션 없이 양이 많다"는 인상. 강제 대명사/연령 모달이 스킵 불가인 점은 UX상 사용자 신뢰를 깎는 전형적 slop 패턴.

## 5. Poe (poe.com)

출처: https://poe.com (2026-08-06 실접속, 비로그인)

1. **첫 화면 구조**: character.ai와 마찬가지로 **완전 로그인 게이트**. 상단에 GPT/Claude/Gemini/Grok/Kimi 등 수십 개 모델 아이콘이 두 줄로 가로 스크롤(마퀴) 배치되고, 그 아래 중앙에 Poe 로고 + 한 문단 설명 + Google/Apple 소셜 로그인 + 이메일 입력 폼. 봇/페르소나 카드 자체는 비로그인 상태에서 전혀 노출되지 않음.
2. **타이포·컬러**: character.ai와 달리 **라이트/화이트 배경에 컬러풀한 원형 모델 아이콘(그라데이션 블롭 아이콘)** 이 유일한 색채. 텍스트는 진회색·블랙, 버튼은 옅은 회색 필. 전반적으로 "AI 모델 마켓플레이스"라는 정체성이 강하고(사용자 제작 캐릭터형 서비스가 아니라 모델 라우팅 서비스) 캐릭터 챗봇 톤과는 결이 다르다.
3. **봇 카드/온보딩**: 확인 불가(게이트). 다만 Poe는 이 리서치의 다른 대상들과 달리 "캐릭터"보다 "모델"이 1급 시민이라는 점에서 참고 가치가 제한적 — 페르소나 카드 그리드 UX 벤치마크로는 부적합.
4. **세련 vs slop**: 판단 근거 부족(콘텐츠 미노출). 다만 로그인 폼 자체는 매우 정갈함(불필요한 장식 없음, 시스템 폰트, 절제된 그림자의 reCAPTCHA 위젯 정도).

## 6. Replika (replika.com)

출처: https://replika.com (2026-08-06 실접속)

1. **첫 화면 구조**: 이 리서치에서 **유일하게 카드 그리드가 아예 없는** 랜딩. 캐릭터를 "고르는" 제품이 아니라 "나만의 AI 친구 한 명"을 파는 제품이라 구조 자체가 다르다 — 하늘색 구름 배경 위에 대형 헤드라인 "The AI friend to do life with", 3D 렌더링된 포토리얼 컴패니언 캐릭터(기타 치는 모습) + 말풍선(문자 알림 재현) + Spotify 카드 목업으로 "일상에 스며든 관계"를 시각적으로 서사화. 스크롤하면 Time/NYT/BBC/TED/Bloomberg/Forbes/Wired/Nature **언론 로고 트러스트 바**, 이어서 "Now, we rebuilt Replika from the ground up" 브랜드 스토리텔링 섹션, "The most emotionally intelligent AI ever built" 기능 섹션(Personality/Memory/Flourishing 탭 전환 데모)으로 이어짐.
2. **온보딩 진입**: "Get started"(상단)와 "Get the app"(히어로, iOS/Android 배지 포함)만 있고 즉시 가입 폼을 들이밀지 않음 — 앱스토어로 유도하는 모바일 퍼스트 전략, 웹에서 채팅을 바로 시작시키지 않는다.
3. **타이포·컬러**: 라이트 테마, 하늘색~흰색 그라데이션 배경. 헤드라인은 두껍고 둥근 산세리프 대형 타이포(임팩트 있는 grotesk 계열, 자간 좁음), 본문은 같은 계열의 절제된 굵기. 포인트 컬러는 코랄/오렌지(CTA 버튼)와 인디고/블루(칩·강조 텍스트) — 파스텔 하늘색 배경과 대비를 이루는 웜톤 CTA.
4. **세련 vs slop**: 이 6개 중 가장 "브랜드 캠페인"처럼 만들어졌다 — 카피라이팅(“ten years ago we built the world's first AI companion. Now we rebuilt it from the ground up.”)이 제품 신뢰도(언론 인용)와 감정적 약속을 같이 판다. 실사풍 3D 캐릭터 + 자연스러운 UI 목업(문자/음악 카드) 합성이 매끄러워 "AI가 만든 티가 나는 이미지"가 아니라 아트디렉션이 들어간 이미지로 읽힌다 — 이 지점이 slop과의 핵심 차이(캐릭터.ai/크랙/제타의 카드 아트는 스톡 일러스트 느낌이 강한 반면 Replika는 브랜드 촬영/렌더링처럼 통일된 라이팅·구도를 씀).
5. **카드/그리드 부재의 시사점**: 멀티봇(여러 캐릭터 중 고르는) 서비스가 아니라 "관계 하나"를 파는 서비스라 이 구조를 그대로 벤치마크할 순 없지만, "카드 그리드 없이도 제품을 설득할 수 있다"는 반례로서 가치가 있다.

## 보너스: Janitor AI (janitorai.com)

출처: https://janitorai.com (2026-08-06 실접속, 비로그인)

1. **첫 화면 구조**: 로그인 없이 전체 캐릭터 목록에 즉시 접근 가능(총 243만+ 캐릭터, 페이지네이션 12,510페이지 노출). 상단 GNB 아래 큰 세리프 디스플레이 헤드라인 **"Be anyone. Build anything."**(디도트/플레이페어류 하이콘트라스트 세리프 — 이 리서치에서 유일하게 세리프를 쓴 사례), 이어 Following/Favorites/Popular/Explore All 탭, "2,436,044 characters" 카운터, 이후 밀집 카드 그리드.
2. **봇 카드 디자인**: 카드 상단에 보라색 얇은 헤더 바(캐릭터 이름), 이미지 위 배지로 대화수(예: 35m)·즐겨찾기수(100). 이미지 아래 **@제작자 핸들 + 인증 체크마크**, 1~3줄 소개, 태그 필(Limitless/Male/Female/OC/Fictional/Multiple/RPG/Scenario/AnyPOV 등)과 해시태그(#mha, #isekai)가 카드 하단에 다시 한 번. 카드 배경이 짙은 보라(#2a1f3d 근사)라 카드 자체가 "물성 있는 판"처럼 도드라짐(크랙·제타처럼 이미지가 카드 전체를 채우지 않고, 이미지+메타데이터가 하나의 보라색 패널 안에 함께 담김).
3. **온보딩 진입**: 언어 전환 모달("한국어로 계속하시겠어요?")만 뜨고 콘텐츠는 그 뒤에서 계속 보임 — 접근 마찰이 가장 낮은 축.
4. **타이포·컬러**: 다크 테마, 딥 퍼플 카드 패널 + 검정 배경. 세리프 헤드라인 + 산세리프 본문의 대비가 "동인/크리에이터 커뮤니티" 톤을 (의도적으로) 문예지풍으로 살짝 격상시킨 느낌.
5. **세련 vs slop**: 태그·배지가 카드 하나에 5종 이상 붙어(이름 바/대화수/즐겨찾기/제작자/설명/태그필/해시태그) 정보 밀도가 리서치 대상 중 가장 높다 — 파워유저(태그로 필터링하며 탐색)에게는 효율적이지만 신규 방문자에게는 "무엇을 봐야 할지 모르겠는" 인지 과부하. 세리프 헤드라인 하나로 톤을 끌어올린 시도는 영리하지만, 그 아래 카드 시스템의 밀도가 그 격상 효과를 바로 상쇄한다.

## 우리 프로젝트(문서기반 멀티봇 챗봇 랜딩)에 훔쳐올 것

1. **크랙의 "가입 없는 개인화" 모달** — 로그인 장벽 없이 한 번의 선택(용도/톤 선택)만으로 이후 화면을 다르게 보여주는 패턴. 우리는 다봇(말문/자리/채광 등)이므로 "지금 필요한 게 뭔가요?"류의 1클릭 분기 진입이 로그인 없이도 가능. (근거: crack.wrtn.ai 첫 방문 온보딩 모달)
2. **크랙 캐릭터 카드의 "이미지+화이트 여백 분리" 구조** — 이미지 위에 텍스트를 얹지 않고 카드 하단 별도 영역에 이름·설명·메타를 배치하면, 어떤 이미지가 오더라도 가독성이 안정적이다. 제타처럼 이미지 위 오버레이 텍스트를 쓰면 대비 관리 실패 리스크가 커진다. (근거: crack.wrtn.ai 캐릭터 탭 vs zeta-ai.io 카드 비교)
3. **Replika의 "카드 그리드 없이도 설득하는 히어로"** — 우리는 봇이 소수(3~8개 내외)이므로 character.ai/크랙처럼 끝없는 그리드를 흉내낼 필요가 없다. Replika처럼 핵심 페르소나 1~2개를 큰 이미지+대화 목업으로 서사화하는 편이 우리 스케일에 맞다. (근거: replika.com 히어로 구조)
4. **Pretendard 채택** — 한국 캐릭터 챗봇 2강(크랙·제타)이 공통으로 Pretendard(Variable)를 쓰는 것은 우연이 아니라 한글 가독성·폭 대비의 검증된 선택. 우리도 이미 한글 UI 기준 폰트로 채택할 근거가 명확. (근거: crack.wrtn.ai, zeta-ai.io computed style 직접 확인)
5. **Replika의 언론/신뢰 로고 바** — 문서기반 챗봇은 "정확성"이 핵심 가치이므로, 언론 인용 대신 "출처 문서 수·감수 절차·기관 로고"류의 신뢰 바를 랜딩 중간에 넣는 방식은 우리 서비스 신뢰도 서사에 직접 응용 가능. (근거: replika.com 스크롤 2번째 섹션)
6. **JanitorAI의 세리프 헤드라인 하나로 톤을 격상시키는 기법** — 카드 시스템은 평범해도 히어로 카피 서체 하나를 하이콘트라스트 세리프로 바꾸는 것만으로 "동인 사이트"와 "매거진"의 인상 차이가 난다. 우리처럼 예산이 크지 않은 랜딩에서 레버리지가 큰 선택. (근거: janitorai.com 헤드라인)

## 절대 하지 말 것

1. **character.ai/Poe식 완전 로그인 게이트** — 우리 서비스는 신뢰가 아직 검증되지 않은 신규 브랜드이므로, 아무것도 안 보여주고 가입부터 요구하면 이탈률만 올라간다. 최소한 봇 소개·대화 예시 정도는 비로그인으로 보여줘야 한다. (근거: character.ai, poe.com 첫 화면 관찰)
2. **Talkie식 닫기 불가 강제 개인정보 모달** — 대명사·연령대를 묻는 모달이 Esc·바깥클릭으로도 안 닫히는 것은 명백한 다크패턴이며, "문서기반 신뢰 챗봇"이라는 우리 포지셔닝과 정반대의 인상을 준다. (근거: talkie-ai.com 강제 모달, Esc 테스트 결과 안 닫힘 직접 확인)
3. **크랙식 배지 과적재** — 카드 한 장에 랭킹 리본 + N배지 + 대화수 + 태그 5개 이상을 동시에 붙이는 것은 우리 같은 소수 정예 봇 라인업에는 전혀 맞지 않는다. 우리는 봇 개수가 적으므로 "인기 랭킹" 서사 자체가 불필요하고 어색하다. (근거: crack.wrtn.ai 캐릭터 카드 배지 밀도)
4. **제타식 데스크톱 미대응(모바일 웹을 그대로 늘린 레이아웃)** — 관리자/직원/부모 세대 사용자가 데스크톱에서도 접속할 가능성이 있는 우리 서비스 특성상, 검정 여백으로 화면 80%를 버리는 레이아웃은 "안 만든 티"가 난다. (근거: zeta-ai.io 데스크톱 접속 시 강제 980px 폭)
5. **JanitorAI/Talkie식 화풍 불일치 그리드** — 실사 인물 사진과 애니메이션 일러스트를 한 그리드에 무작위로 섞으면 브랜드 톤이 산으로 간다. 우리는 봇 아이콘/캐릭터 이미지의 아트 디렉션을 하나로 통일해야 한다(스타일 가이드 필수). (근거: talkie-ai.com 그리드에서 포토리얼×애니메이션 혼재 관찰)
6. **제타식 로그라인 자극 카피 그대로 노출** — "남편의 내연녀가 되었다" 같은 자극적 한 줄 요약을 카드에 그대로 노출하는 방식은 로맨스 판타지 장르 소구에는 맞아도, 우리처럼 신뢰·정확성이 핵심인 문서기반 챗봇에는 절대 어울리지 않는다(톤이 완전히 다른 카테고리). (근거: zeta-ai.io 카드 카피 관찰)
7. **크랙식 끝없는 가로 스크롤 레일 중첩** — "QWER 콜라보"·"공식 오리지널"·"신예 창작자"·"공식 크리에이터 신작"·"요즘 트렌드"처럼 유사한 레일을 홈에 6개 이상 쌓는 구조는 봇 개수가 적은 우리 서비스엔 채울 콘텐츠가 없다 — 억지로 따라하면 빈 레일이나 억지 카테고라이징만 남는다. (근거: crack.wrtn.ai 스크롤 전체 관찰)
