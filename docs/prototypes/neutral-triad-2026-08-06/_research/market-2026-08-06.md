## 1. 캐릭터 챗봇 제품

Character.AI / Talkie / Replika / 제타(Zeta, 스캐터랩) / Janitor AI / Moemate / Crushon.ai 조사.

### Character.AI

- 비로그인 상태로 루트 도메인에 접속하면 캐릭터 그리드가 아니라 즉시 회원가입 게이트가 뜬다. 헤드라인 "Get access to 10M+ Characters" / 서브카피 "Sign up in just ten seconds", 버튼은 Google 계속하기 → Apple 계속하기 → "OR" 구분선 → 이메일 계속하기 순 3단 스택. 캐릭터 미리보기 없이 가입 폼이 히어로를 통째로 차지한다 (직접 확인, https://character.ai/).
- 로그인 이후 대시보드는 "스트리밍 서비스처럼 좌측 사이드바 + 트렌딩 캐릭터 행 + 'Scenes'(사전제작 롤플레이) 전용 행" 구조 (직접 접근 불가, 리뷰 기반: https://techpoint.africa/guide/character-ai-review/).
- 가입은 이메일 인증 또는 Google/Apple 소셜 로그인, 가입 즉시 "ArrogantFish7437" 식 랜덤 닉네임 부여 (https://techpoint.africa/guide/character-ai-review/).
- 정확한 색상 hex는 확인 불가(Next.js 번들 난독화). 리뷰 공통 서술은 "다크 테마, ChatGPT/Deepseek 유사 채팅 인터페이스" (https://www.wpcrafter.com/review/character-ai/).

### Talkie

- 로그인 없이도 캐릭터 카드가 바로 노출. 히어로 상단 "Are you... Looking for connections?" 문구 옆 무드 이모지 탭 4개(🥰🥳😈🤪)가 카테고리 필터처럼 배치, 아래 가로 카드 리스트 (직접 확인, https://talkie-ai.com/).
- 카드 = 배경 이미지(인물 일러스트/실사풍 혼재) + 캐릭터명 + 세계관 한 단락 + "Reply" 버튼 + 채팅 수 뱃지(8.9K, 56.7K 등).
- 좌측 고정 사이드바 7개 탭(Create a Talkie / Image Create / Discover / Search / Community / Memory / Talkie Claw) — 캐릭터 탐색과 창작 도구를 같은 레벨 내비게이션으로 묶음. 우측 상단 "Unlock with Talkie+ -50%" 배지 상시 노출.
- 배경색 `#1C1D20`(다크 그레이, meta 태그 직접 확인).
- 가입은 이메일+비밀번호(선택적 전화번호)로 짧고, 게스트로 샘플 대화 열람 가능. 첫 캐릭터 선택 즉시 음성 채팅 UI로 진입시키며 마이크 권한을 반복 요청(텍스트만 쓰려면 2번 거부 필요) (https://bestieai.app/topics/wellness/how-to-use-talkie-ai-app-guide, https://scribehow.com/o/cu8NZNXQRJyqQn3q1GQK1w).

### Replika

- 유일하게 "N개 캐릭터 그리드" 구조가 없음 — 1유저=1 AI 친구 모델. 랜딩은 "당신"을 중심으로 한 동심원 다이어그램(관계/성향/취향)과 다수 사용자 사례(Theo, Katelyn, Nicolara, Leo, Igo Yan 등 각기 다른 반려 AI)를 소셜 프루프 스토리로 배치 (직접 확인, https://replika.com/).
- 히어로 카피 "The AI friend to do Life With" + 유스케이스별 서브카피("becoming yourself", "doing life", "side quests", "falling in love") 반복. CTA는 항상 "Get the app"(앱스토어 링크) 하나로 통일, 웹 텍스트 채팅 진입점 없음.
- 화이트 배경 + 다크 텍스트 고대비, 안개 낀 아날로그 사진 악센트 — 타 서비스의 다크테마/보라 계열과 대조.
- 아바타는 원형 프로필이 아니라 커스터마이즈 가능한 카툰풍 3D 캐릭터, 최초 온보딩에서 이름·나이·외형 순차 설정 (https://help.replika.com/hc/en-us/articles/360046050652, https://www.vidnoz.com/ai-solutions/replika-avatar.html).

### 제타 (Zeta, 스캐터랩)

- `zeta-ai.io/ko` 비로그인 즉시 캐릭터/스토리 카드 그리드 노출. 최상단 배너는 "1st Creation Contest"(지역별 참가 건수 실시간 카운터) — 캐릭터 서비스인데 UGC 창작 콘테스트를 최상단에 광고. 아래 Popular/Featured 탭 + 장르 필터 칩(Romance & Relationships / Adventure / Mystery / Simulation / Slice of Life) (직접 확인, https://zeta-ai.io/ko).
- 카드 = 세로 커버 이미지(일러스트풍) + 조회수(387K 등) + 제목 + 한 줄 후크 카피 + 해시태그 칩(#darkromance 등, 클릭 시 태그 검색 연결) — 그리드가 곧 검색 필터.
- 배경 `#151516`, 액센트 보라-바이올렛 `#6728FF`/`#8728FF`, 그린 포인트 `#2b8813`.
- 카카오/Google/Apple/이메일 가입, 무료 무제한 대화 + 대화 기반 일러스트 자동생성이 핵심 셀링포인트 (https://gusle.kr/zeta-ai-site-access/, https://www.moket.kr/tools/zeta-ai, https://www.nextreview.kr/article/202605270002).

### Janitor AI

- 로그인 없이 즉시 캐릭터 그리드. 히어로 "Be anyone. Build anything." + "Join 15M+ users crafting living stories", 바로 아래 "⭐ Popular" 섹션 (직접 확인, https://janitorai.com/).
- 카드 구성이 가장 촘촘함: 세로 썸네일 + 캐릭터명 + 채팅수 + 좋아요수 + 제작자 핸들(@KLOOMSY) + 설명 + 별 아이콘 + **토큰 수 뱃지**(462 tokens, 3.6k tokens — 캐릭터 설정 프롬프트 길이를 파워유저 지표로 노출, 타 서비스엔 없는 특이점).
- 배경 `#313338`/`#313339`(Discord 다크테마와 거의 동일 — 디스코드 커뮤니티 기반 성장과 일치), 액센트 라이트퍼플 `#a388ee`, 페일 라벤더 `#e0d3ff`.

### Moemate

- 2026-08 기준 원 서비스는 종료(2025-02-11 이후 오프라인, 유저 데이터 전량 삭제). `moemate.chat`은 실서비스가 아니라 Crushon.ai로 넘기는 어필리에이트 랜딩("Try It For Free" → `crushon.ai/?from=moemate&utm_source=...` 리다이렉트) (직접 확인, https://moemate.chat/; 종료 경위: https://www.roborhythms.com/what-happened-to-moemate-ai/, https://www.zuloai.com/blog/moemate-ai-the-rise-and-sudden-fall-of-a-groundbreaking-ai/).
- 생전 구조(리뷰 기반 재구성): 캐릭터 생성 화면이 "Basic Info"(성격·바이오·샘플 대사) / "Avatar"(2D 생성·업로드 또는 3D 모델 업로드, Ready Player Me·VRoid Hub·Chub.ai 연동) 2탭. 애니메 스타일 아바타 + Live2D 연동 (https://aimojo.io/tools/moemate/, https://creati.ai/ai-tools/moemate/).
- 시사점: 캐릭터 챗봇 시장은 제품 수명주기가 짧고(생성 1년 반 만에 폐업), 도메인이 곧바로 경쟁사 어필리에이트로 재활용될 만큼 회전율이 높다.

### Crushon.ai

- 로그인 없이 그리드 접근. 1차 내비게이션: Home / Recent Chats / Create / Rankings / Profile / Pricing / Store / Bonus / Notifications — 캐릭터 열람뿐 아니라 크리에이터 경제(Rankings, Store, Bonus/코인)가 나란히 배치 (직접 확인, https://crushon.ai/).
- 첫 방문 시 모달 "Which gender are you interested in?"(Female/Male/Non-binary 아이콘 카드) — 이 선택 후에야 개인화된 그리드가 채워짐. 그리드 위 "Discover" 드롭다운 + "gender all" 필터 + "Animated"/"Unfiltered" 토글. 배경 `#313131`.
- "No Filter NSFW Character AI Chat"을 타이틀에 명시할 만큼 성인 콘텐츠가 핵심 포지셔닝, 풋터에 2257 기록보관 준수·연령 정책 링크.

### 이 영역에서 참고할 구체적 패턴

1. **"관심사 1문항 온보딩 후 그리드 채우기"** (Crushon.ai) — 무거운 설문 대신 아이콘 3개짜리 즉답형 1문항으로 개인화 신호를 받고 카드 배열을 바꾼다. RAG 챗봇이면 "어떤 문서/역할을 찾으시나요" 1문항으로 응용 가능.
2. **"태그가 곧 검색 필터"** (제타) — 카드 해시태그가 클릭 가능한 검색 링크를 겸함. 별도 카테고리 탭 없이 그리드+태그 하나로 N-가변 로스터 해결.
3. **카드에 신뢰 신호 수치 노출** (Janitor AI) — 채팅수·좋아요·토큰(설정 분량). RAG라면 "인용 문서 수", "최근 업데이트일", "이용 횟수"로 변형 가능.
4. **로그인 게이트 vs 그리드 우선의 트레이드오프** — Character.AI만 유일하게 그리드 대신 가입 폼을 먼저 보여줌(1위 사업자만 가능한 선택). 신규 서비스는 콘텐츠 먼저, 가입은 액션 시점에 요구하는 게 안전.
5. **단일 캐릭터형 대안 구조** (Replika) — 봇이 소수라면 그리드 대신 "관계도+실사용자 사례"형 레이아웃이 대안.

## 2. RAG/문서 Q&A 챗봇 SaaS

NotebookLM, ChatPDF, Humata, AskYourPDF, Chatbase, CustomGPT.ai, SiteGPT, Mendable, Onyx(구 Danswer), Glean, Dust 11개 실제 랜딩을 직접 열람(WebFetch + Jina Reader 원문 대조)해 조사. 카피 원문 인용은 페이지 원본과 대조 확인.

### NotebookLM (Google) — 2026년 7월 "Gemini Notebook"으로 리브랜드

출처: https://notebooklm.google/

- FAQ: "NotebookLM is now Gemini Notebook as of July 2026." — 카테고리 대표 제품명 자체가 바뀜.
- 히어로: H1 "Understand Anything" / 서브 "Your research and thinking partner, grounded in the information you trust, built with the latest Gemini models."
- 인용/근거 UI: 기능 블록 "See the source, not just the answer" — "provides clear citations... showing you the exact quotes from your sources." 각 블록마다 자동재생 mp4 데모(정적 스크린샷 아님).
- FAQ: "Gemini Notebook's advantage is being source-grounded... reducing the likelihood of AI errors and hallucinations."
- 소셜프루프: 고객 로고·통계 섹션 없음. 대신 언론/저명인 인용 캐러셀만("Blew Our Mind" - HardFork, CNBC, Barron's, WSJ, The Verge, Andrej Karpathy X 인용). 가격 섹션 없음(별도 /plans).

### ChatPDF

출처: https://www.chatpdf.com/

- 히어로: "ChatPDF in a Nutshell" / "Your PDF AI - like ChatGPT but for PDFs. Summarize and answer questions for free."
- 인용/근거 UI: "Cited Sources — Built-in citations anchor responses to PDF references." FAQ: "clickable citations instantly scroll to the exact source in your PDF." "NAVIGATE — Side-by-Side View": PDF 뷰어와 채팅창을 좌우 분할, 답변-원문을 링크로 연결 — **인용 UI의 가장 구체적 구현 사례**.
- 데모: 기능별 정적 일러스트. 라이브 위젯 없음.
- 요금: 히어로 없이 FAQ에만 — Free(일 2문서), Plus(무제한).
- 소셜프루프: 로고월·통계 섹션 확인 안 됨(주의: WebFetch 요약 모델이 "1000만+ 사용자, Harvard/Stanford 로고"를 언급했으나 Jina 원문 재확인 시 없음 — 요약 모델 오류로 판단).

### Humata

출처: https://www.humata.ai/

- 상단 "Trusted by top investors"(고객이 아닌 **투자자** 로고 밴드 — 초기 스타트업의 특이 신뢰 패턴). 실질 헤드라인: "Your team can't read it all. But Humata can."
- 인용/근거 UI: "Highlights citations — Build trust with cited links into your source files... so you can trace where your insight came from." 아이폰 목업 이미지와 짝.
- 요금: Free $0(60p, 답변 10회) / Expert $9.99 (500p 무료+초과 $0.02, 3인) / Team $49/인 (5,000p+초과 $0.01, 10인, OCR) / Enterprise.
- 소셜프루프: 실명+직함+사진 후기 4건(HFS Research CEO, UC Irvine 부교수 등) — 신뢰도 높은 형태.

### AskYourPDF

출처: https://askyourpdf.com/ , /pricing

- 포지셔닝 이동: "Chat With Any PDF" 섹션 자체가 "Also included — The feature that started AskYourPDF"로 표현 — 원래 기능을 스스로 서브 기능으로 격하.
- 히어로: "Trusted by 5M+ users worldwide" / H1 "The AI Chatbot for Your Website, Trained on Your Content". CTA 2개: "Build your AI agent" + "Try Our GPT"(OpenAI GPT 스토어 연동, 보조 신뢰 신호).
- 소셜프루프: MIT/Harvard/Oxford/Stanford/UCL 등 **대학** 로고("고객사"가 아니라 "이 학교 사람들이 씀"). 후기는 실명 대신 "@Mercy" 식 핸들+오탈자 그대로 — Humata 대비 신뢰 격이 낮음.

### Chatbase

출처: https://www.chatbase.co/ , /pricing

- 포지셔닝: "문서 학습 챗봇"→"CX 전담 AI 에이전트"로 완전 이동. 히어로에 G2 평점 "4.8" 인라인 배지. H1 "Conversational agents for customer experience". 근거표시는 더 이상 헤드라인이 아니라 암묵적 인프라.
- 인용/근거 UI: Pro 플랜 설명에만 "Sources suggestions" 짧게 언급 — 핵심 셀링포인트 아님.
- 데모: 15개 고객 로고 밴드(Dolby, Pearson, Roche 등, 흑백→컬러 호버). Agent lifecycle 섹션은 Instructions/Guardrails/Model(Claude Sonnet 4.6)/Actions 설정 화면 스크린샷.
- **특이 패턴**: 페이지 하단에 "Ask Perplexity/ChatGPT/Claude about this product" — 벤더 카피 대신 제3자 AI로 직접 검증하도록 유도하는 2026년형 AEO(Answer Engine Optimization) 신뢰 장치.
- 인용: Marc Manara(OpenAI, Head of Startups) — 경쟁 관계일 수 있는 인물의 인용을 신뢰 신호로 사용.
- 요금: Free/$32 Hobby/$120 Standard("Popular")/$400 Pro/Enterprise, 크레딧 기반.

### CustomGPT.ai

출처: https://customgpt.ai/

- 다층 헤드라인: "Every AI answers questions. Create one you trust." / "Go live in 15 minutes with custom AI that accurately cites your information." "7-day trial" + 자동재생 히어로 비디오.
- 인용/근거 UI: "third-party verified #1 for anti-hallucination technology, beating out major players like OpenAI and Google" — **경쟁사를 직접 지목하는 공격적 차별화 문구**. "every response has a link directly to its source."

### 이 영역에서 참고할 구체적 패턴

1. **"근거(grounding)" 문구는 이미 카테고리 표준어** — NotebookLM "source-grounded", Humata "cited links", ChatPDF "anchor responses", CustomGPT "link directly to its source", Onyx "grounded in..." 거의 전원이 동일 개념 반복. 텍스트 주장만으론 차별화 안 됨 — **각주 클릭→원문 하이라이트 스크롤 이동 인터랙션을 짧은 영상으로 명확히 보여주는 것**이 카피보다 중요(ChatPDF side-by-side가 가장 구체적 사례).
2. **"단순 문서 Q&A"만으로는 커머디티화·소멸 리스크** — Mendable 폐업이 실증. Chatbase/Dust/Glean/AskYourPDF 모두 "문서 답변"을 최종 목적지가 아닌 더 큰 가치(매출·시간절감·워크플로우)의 수단으로 재포지셔닝. 헤드라인은 "문서 기반 답변" 자체보다 **구체적 업무 결과**를 걸어야.
3. **정량 벤치마크가 카피보다 강한 신뢰 장치** — Onyx(측정 방법론 명시), CustomGPT("제3자 검증 1위"), Glean(오도미터 애니메이션 수치)처럼 방법론을 한 줄이라도 명시한 숫자가 "정확합니다"보다 설득력 큼.
4. **라이브 인터랙티브 데모는 소수만 시도, 도그푸딩이 효과적** — 11개 중 SiteGPT만 실제 라이브 챗을 넣음("자기 제품 문서로 자기 제품을 답하게"). 나머지는 mp4/정적 목업 — 라이브 위젯의 응답 지연·이상답변 리스크 회피. 넣는다면 자사 문서/FAQ 범위로 한정.
5. **소셜프루프의 "격"은 타겟 시장에 맞춰야** — 개인용 툴(ChatPDF/AskYourPDF/Humata)은 대학 로고+캐주얼 후기, 엔터프라이즈 툴(Glean/Dust/Chatbase/CustomGPT)은 실명+직함+정량 성과. B2B 타겟이면 정성 감상보다 **직함+정량 결과 인용**을 우선 확보.
6. (참고) Chatbase의 "Ask Perplexity/ChatGPT/Claude about this product" — 벤더 카피 대신 제3자 AI 검증을 유도하는 2026년형 신뢰 장치. 시도해볼 만한 새로운 패턴.

- 뻔함: Pinterest에 반복되는 "Chat Bot Isometric Landing Page Template" 스톡 벡터, Behance 학생 프로젝트 "Genius" — 공통점은 (1) 아이소메트릭 로봇+말풍선 클립아트, (2) 공허한 카피, (3) 브랜드 근거 없는 퍼플-블루 배경 그라디언트 남용. Lapa Ninja 2018년식 Bot 카테고리도 지금 기준 낡은 문법.

### 이 영역에서 참고할 구체적 패턴

1. 로봇 마스코트·말풍선 스톡 아이콘 대신 실제 대화 화면(인용 출처 표기 포함)을 히어로에 스크린샷/모크업으로 노출.
2. 팔레트는 딥인디고+라벤더(따뜻한 AI톤) 또는 니어블랙+일렉트릭블루(개발자/엔터프라이즈톤) 중 하나로 2~3색만 절제, 브랜드 컬러 1색만 예외적 액센트.
3. 정적 스크린샷보다 짧은 루프 영상(로딩 진행, 답변 생성 중 상태)이 최근 큐레이션 갤러리에서 우세 — RAG 특유의 "문서를 찾아 답변을 조립하는 과정"을 진행 인디케이터로 짧게 보여주면 신뢰감.
4. 타이핑 인디케이터는 채팅 UI 자체보다 랜딩 히어로 데모 루프에 넣어 "실제 작동"을 증명하는 용도로.
5. 아이소메트릭 로봇, "상상을 혁신으로" 식 공허한 카피, 근거 없는 퍼플-블루 그라디언트는 의도적으로 피할 것.

### B. "에이전시급"으로 읽히게 만드는 구체 기법

**타이포그래피 스케일**
- 8pt/4pt 그리드 기반 모듈러 스케일로 헤드라인-본문 크기 대비 설계 — https://www.freecodecamp.org/news/8-point-grid-typography-on-the-web-be5dc97db6bc/
- 글꼴 2~3개 제한, 본문 줄간격 1.5~1.8, 줄 길이 50~75자, WCAG 대비(본문 4.5:1) 준수.
- 사례: Linear(커스텀 수정 서체), Stripe(비스포크 세리프 헤드라인), Vercel(자체 폰트 Geist 커미션) — Inter 기본값을 안 쓰는 것 자체가 "의도적 스타일링"의 신호 — https://www.925studios.co/blog/ai-slop-web-design-guide

**그리드 파괴/비대칭 레이아웃**
- 2025~2026 트렌드: "완벽한 그리드 규칙을 깨는" 비대칭 레이아웃으로 창의적 역량을 레이아웃 자체로 신호 — https://thehypedge.com/the-rise-of-asymmetric-layouts-breaking-the-mold-in-web-design/
- Awwwards급 사례: Targo(레드/블랙+클리핑 코너), Logoisum(기울어진 릴 그리드), Jack3D(스티키 스태킹 카드), Mindloop(순수 블랙+스크롤 워드 리빌) — 이런 "카오스"도 실제로는 숨겨진 그리드 위의 통제된 결과 — https://sitesplaced.com/blog/creative-landing-page-examples-2026

**모션 절제**
- "1~2개의 잘 배치된 애니메이션이 모션의 불꽃놀이보다 큰 차별화" — 애니메이션 300ms 이내, 바운스 없는 절제된 스크롤 페이드인/보더빔/마퀴로 한정 — https://www.monet.design/blog/posts/escape-ai-slop-landing-page-design

**컬러 팔레트 제약**
- Mistral: 보라 대신 픽셀아트+오렌지 악센트로 전문성 유지하며 개성 확보. Scale AI: 추상 이미지 대신 실사 사진 — https://www.designrush.com/agency/website-design-development/trends/ai-startup-homepage-design
- 디자인 토큰(`--color-brand` 등)을 프레임워크 기본값보다 먼저 정의, OKLCH 등 지각적 색공간으로 WCAG 대비 보장하며 팔레트 일관성 유지 — https://dev.to/jaainil/ai-purple-problem-make-your-ui-unmistakable-3ono

**커스텀 비주얼, 카피, 작업 방식**
- 스톡 대신 커미션 촬영·일러스트로 브랜드 고유 시각언어 확보 — https://unpromptable.substack.com/p/5-ai-website-design-tips-for-websites
- "Build the future of work" 류 막연 카피 대신 대상별 구체적 니즈 대응 카피.
- AI 디자인의 근본 문제는 "생성→육안 확인→같은 문제 수동 수정"의 원샷 워크플로우. 시니어급 결과물은 생성→체크리스트 비평→우선순위 수정→재평가의 반복 루프에서 나옴 — https://smoothui.dev/blog/ai-design-slop

### 새 RAG 챗봇 랜딩이 반드시 피해야 할 것

1. Tailwind `indigo-500` 계열 보라-파랑 그라디언트(히어로 배경, 버튼, 텍스트 그라디언트) — 가장 확실한 "AI가 만들었다" 신호.
2. Inter(무수정 기본 산세리프) 단독 + 완전 중앙정렬 히어로 + 배지-H1-서브카피 획일 구조.
3. 동일 padding·border-radius·카드 높이의 3열 아이콘 카드 그리드, 카드 좌측/상단 컬러 보더 스트립.
4. "Build the future of ~" 류 막연 카피, 이모지 불릿, 전대문자 라벨 남용.
5. 노트북 앞 다인종 스톡사진, 아이소메트릭/그라디언트 블롭 일러스트, 글래스모피즘+블러 배경.
6. 반응 없는 호버, 이징 없이 스냅되는 버튼, 획일적 스크롤 페이드인.

### 반드시 갖춰야 할 것

1. 헤드라인-본문 극단 크기 대비 타이포 스케일(8pt/4pt 그리드), 폰트 2~3종 제한(최소 1종 커스텀/브랜드 전용).
2. 명시적으로 정의한 2~3색 팔레트(가능하면 OKLCH 기반)를 프레임워크 기본값보다 먼저 확정.
3. 완전 대칭·중앙정렬 대신 오프센터 히어로, 코너 스탯 블록 등 통제된 비대칭 요소 최소 1군데.
4. 스톡 대신 커스텀 촬영/일러스트, 또는 실제 제품 스크린샷·실제 대화 로그.
5. 애니메이션 300ms 이내, 1~2개의 의도된 마이크로인터랙션만.
6. 카피는 추상적 약속 대신 구체적 숫자·구체적 사용 시나리오.

## 5. 새 랜딩에 훔쳐올 만한 구체적 패턴 (종합)

네 영역을 관통해서 우선순위가 높은 순으로 정리.

1. 로봇 마스코트·말풍선 스톡 아이콘을 쓰지 않는다. 실제 질문-답변+인용 출처가 보이는 대화 화면을 히어로에 스크린샷/모크업으로 그대로 노출한다 (근거: land-book Clarasight/Octolane, godly.design Parloa).
2. "근거(grounding)" 카피는 이미 카테고리 전원이 쓰는 표준어다. 텍스트 주장 대신 **각주 클릭 → 원문 위치로 스크롤 이동하는 실제 인터랙션**을 짧은 영상으로 보여준다 (근거: ChatPDF의 side-by-side 뷰가 가장 구체적).
3. Tailwind `indigo-500`류 보라-파랑 그라디언트와 다크테마 남용을 피한다. 데이터로 입증된 1위 AI 신호다(Show HN 분석 22% heavy slop, 다크테마 34%/그라디언트 27%/카드그리드 22%, 레딧 320만 건 마이닝에서도 1위).
4. 팔레트를 2~3색으로 명시적 제약한다. 딥인디고+라벤더(따뜻한 AI톤, Clarasight) 또는 니어블랙+일렉트릭블루(엔터프라이즈톤, Set Space) 중 하나를 고르고 브랜드 고유 액센트 1색만 예외로 둔다.
5. Inter 단독 + 완전 중앙정렬 + 배지-H1-서브카피 획일 구조를 피한다. 최소 1종은 커스텀/비-기본 서체를 쓴다(Linear/Stripe/Vercel 사례).
6. 동일 padding·border-radius의 3열 아이콘 카드 그리드, 카드 좌측 컬러 보더 스트립을 피한다 — 텍스트의 em-dash처럼 AI 신호로 이미 낙인찍힌 패턴이다.
7. 오프센터 히어로, 코너 통계 블록 등 통제된 비대칭 레이아웃을 최소 한 군데 배치해 그리드가 살아있음을 보여준다.
8. 정량 벤치마크(측정 방법론 명시)를 카피성 주장보다 우선한다 — Onyx("vs ChatGPT/Claude/Notion, 독립 LLM 심사위원 2명, 99문항×22만 문서로 블라인드 채점")가 가장 구체적인 참고 사례.
9. "문서 Q&A" 자체를 최종 목적지로 걸지 않는다. 구체적 업무 결과(시간 절감%, 응답률, 상담 대체 건수)를 헤드라인급으로 건다 — Mendable 폐업 사례가 반증이다.
10. 라이브 데모를 넣는다면 SiteGPT처럼 자사 문서/FAQ 범위로 한정한 도그푸딩 방식을 쓴다. 조사 대상 11개 SaaS 중 유일하게 이 방식을 썼고 나머지는 리스크 때문에 mp4/정적 목업을 택했다.
11. 소셜프루프의 격을 타겟에 맞춘다 — B2B라면 실명+직함+정량 성과("80% adoption", "1.5+ hours saved weekly")가 붙은 인용을, 개인/커뮤니티 대상이라면 학교·커뮤니티 로고와 캐주얼 후기를 쓴다.
12. "관심사 1문항 온보딩"으로 콘텐츠 그리드를 개인화한다 (Crushon.ai) — 무거운 설문 대신 아이콘 3개 즉답형으로.
13. 태그/카테고리가 검색 필터를 겸하게 해서 N-가변 로스터(봇/문서 카테고리)를 그리드+태그 하나로 해결한다 (제타 패턴).
14. 카드에 신뢰 신호 수치(인용 문서 수, 최근 업데이트일, 이용 횟수 등)를 노출해 파워유저 신뢰를 확보한다 (Janitor AI의 채팅수/토큰수 패턴 변형).
15. 신규 서비스는 Character.AI식 "그리드 대신 가입 폼 우선"을 피한다. 콘텐츠 먼저 보여주고 가입은 액션(실제 대화 시작) 시점에 요구하는 편이 안전하다.
16. 봇/문서 수가 적다면 그리드가 필수는 아니다. Replika처럼 "관계도+실사용자 사례"형 개인화 레이아웃도 유효한 대안이다.
17. 정적 스크린샷보다 짧은 루프 영상(로딩 진행바, 답변 생성 중 상태 표시)을 히어로에 넣는 편이 최근 갤러리에서 우세하다 — RAG 특유의 "문서를 찾아 답변을 조립하는 과정"을 진행 인디케이터로 보여주면 신뢰감을 준다.
