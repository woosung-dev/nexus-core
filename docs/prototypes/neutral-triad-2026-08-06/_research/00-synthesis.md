# 종합: 3안 발산 매트릭스 — neutral-triad-2026-08-06

작성일 2026-08-06. 신규 조사 01·02 반영. 03(디자인 인사이트)·04(딥리서치)는 세션 한도로 보류 중,
도착하면 이 문서의 "보류 반영분"에 추가한다. unbound 라운드 조사 04(프리미엄 실측)·05(한글 조판)는 그대로 유효.

이번 라운드 전제(인터뷰 확정): **완전 중립 셸** + 안별 새 브랜드 제안 + 상용 B2C 톤 + 공통 콘텐츠 팩(`_content.md`).
계승은 "문서 기반 챗봇 기능" 하나뿐.

## 신규 조사가 준 결론 (01·02)

1. **AI 고지·근거 문구는 1급 UI다.** character.ai는 전 채팅 화면 상시 노출, 크랙은 업데이트 로그에 묻음.
   신뢰를 파는 서비스라면 근거 상태 라벨과 AI 안내를 부가정보가 아니라 매 응답 동반 요소로. (01)
2. **"trust / actually" 계열 신뢰 수사는 레드오션.** Glean·Allganize·Upstage·CustomGPT가 전부 같은 문구.
   차별화는 조항 단위 구체성("§12조·표 2·4쪽")으로만 가능하다. (02)
3. **봇 카드 그리드형 로스터는 상용 선례가 사실상 없다.** Glean=기능 목록, Onyx=설정값 목록,
   Dust=대화 참여자 피드. 카드 그리드 대신 각 안이 서로 다른 로스터 은유를 실험한다(아래 매트릭스). (02)
4. **다크패턴·이중 과금·가격 숨김은 리뷰·규제에서 실측된 신뢰 비용.** 프로토타입에도 결제 유도·닫기 불가
   모달·블러 유도 장치류 표현 금지. (01)
5. **소수 정예 로스터는 이름의 서사가 중요.** 규모(천만 캐릭터)로 못 밀면 이름에 이야기가 있어야 한다.
   안별 서비스명 제안 시 유래 한 줄을 같이 쓸 것. (01)
6. **어시스턴트/봇 지칭은 사용자 눈높이 단어로.** "Agent"는 관리자용 어휘라는 업계 관행. 셸 카피에서는
   "봇" 또는 안별 제안 명칭을 쓴다. (02)
7. **크림 배경·오버사이즈 이탤릭 세리프 헤드라인은 2026-08 기준 슬롭 신호로 역전됐다**(impeccable.style
   51패턴). fd의 쿨 페이퍼 선택 근거. 이탤릭 세리프 헤드라인은 전 안 금지. (03)
8. **챗 실물은 Attio식 "히어로 아래 정적 트랜스크립트"가 가장 깨끗한 증명.** 로봇 아이콘·스파클 없이
   실제 대화로 능력을 보여준다. 랜딩 근거 실물 섹션의 기준. (03)
9. **마퀴 티커 판단 기준: 핵심 가치어 반복은 허용, 실제 정보 전달용은 금지**(두 소스 충돌의 절충).
   일본 프리미엄 조판의 실체는 모노크롬+여백+산세리프, 명조는 국소 포인트만. (03)

## 전 안 공통 하드룰

- `_content.md`의 금지어·목대화·로스터·하드룰 다이제스트 전부 준수(콘텐츠 동일 = 대조 성립 조건)

## 3안 발산 매트릭스 (구속력 있음 — 각 빌드 에이전트는 자기 행만 따른다)

| 안 | 스킬 | 방향명 | 랜딩 골격 | 컬러 월드 | 타이포 축 | 로스터 은유 | 채팅 인용 기전 |
|---|---|---|---|---|---|---|---|
| **ui** | ui-ux-pro-max | **콘솔(Console)** | 앱 셸 스플릿 — 좌측 고정 레일 + 우측 캔버스. 랜딩 첫 화면이 곧 제품 셸이고, 우측 캔버스를 스크롤하면 소개 섹션이 이어진다 | 라이트 뉴트럴 + 코발트 블루 1색 | Pretendard 단일, 제품형 정밀(tabular-nums, 좁은 자간) | 좌 레일 "대화 참여자 목록"형(이니셜 아바타 + 이름 + 담당 문서 수) | 인라인 번호 각주 → 우측 소스 시트 슬라이드(판본·조항·원문 발췌, 근거 대목 하이라이트) |
| **fd** | frontend-design | **서사(Narrative)** | 세로 챕터 시퀀스 — 풀와이드 챕터들이 스크롤을 따라 실제 대화 한 벌을 단계별로 재생(질문 → 문서 조회 → 인용 도착 → 답) | 쿨 페이퍼(아이스 그레이 계열) + 딥 버건디 액센트 | 마루부리 세리프 디스플레이 + Pretendard 본문 | 참고문헌 색인형(번호 매긴 서지 리스트, 카드 아님) | 답변 바로 아래 펼쳐진 서지형 출처 블록(세리프 인용 원문 + 판본 표기) |
| **ts** | taste-skill | **원문(Verbatim)** | 다크 테마락 모듈러 그리드 — 비대칭 오버사이즈 타이포 + 대형 넘버 인덱스 섹션, 중앙 정렬 아님 | 잉크 네이비 다크 + 페이퍼 화이트 + 형광펜 옐로(근거 대목 전용 의미색, 글자색 아님) | SUIT 800 헤비 디스플레이 + 모노 라틴 메타 라벨 | 전폭 로우 스택(봇 하나가 화면 전폭 한 줄, 호버 시 확장) | 답변 문장 하이라이트 ↔ 원문 대조 팝오버(형광펜 기전: 클릭하면 원문 발췌의 같은 대목이 형광 표시) |

- 라이트 2(ui·fd) : 다크 1(ts). 액센트 3색 상이(코발트/버건디/형광옐로+네이비). 세리프 1(fd).
- 로스터 3형 전부 카드 그리드 아님(조사 결론 3 반영), 서로소.
- 헤드라인 초안(각 스킬 방법론으로 정련, 수동 개행 6~12자):
  ui "긴 약관, / 묻는 게 빨라요" · fd "답에는, / 출처가 따라와요" · ts "근거 없는 답은 / 여기 없어요"
- 서비스명: 안별 새 제안(한/영 재량) + 유래 한 줄. 기존 명칭(Nexus·블레싱) 재사용 금지.

## 이식 스펙 (unbound 04·05 실측 합의점 — 그대로 유효)

- 타입: 본문 15~16px / 행간 1.5~1.62 / 자간 0~-0.01em. 디스플레이 48~64px / 행간(한글) 1.25~1.3 /
  자간 -0.02~-0.03em(하한 -0.04em). 웨이트 400↔700(800) 점프.
- 간격: 4px 스케일, 섹션 100~130px, 컨테이너 1152~1280, 산문 640~720(한 줄 25~45자).
- 표면: 배경/카드/침몰 3단 명도, `color-mix(in oklab, ...)` 파생 계층. 본문 순검정 금지.
- 모션: 호버 120~160ms ease-out, 진입 opacity+translateY≤16px 400ms 스태거 60ms, 그 이상 금지.
