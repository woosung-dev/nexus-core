# neutral-triad-2026-08-06 — 중립 셸 3-스킬 라운드 (7회차)

완전 중립 셸 라운드. 기존 구조(Nexus 앰버 포털·블레싱 보라 계열)를 전부 버리고
**"문서 기반 챗봇" 기능 하나만 계승**해, 랜딩+챗 프로토타입을 만들었다.
관리자 참고축(character.ai·크랙)과 반대 방향인 "근거를 파는 프리미엄"이 공통 명제.

**병렬 2세션이 같은 브리프·같은 콘텐츠 팩으로 각자 3안을 만들어 총 6안(스킬당 2안)이다.**
1차분 A/B/C(`ui`·`fd`·`ts`)와 2차분 D/E/F(`ui-product`·`fd-editorial`·`ts-precision`)는
서로를 모르는 상태에서 제작됐다 — 같은 스킬이 두 번 다르게 푼 자연 실험이기도 하다.

## 인터뷰 확정 (2026-08-06)

- 브랜드: 중립 셸 + **안별 새 브랜드 제안**(서비스명·색·타이포 각자)
- 화면: 랜딩 + 챗(인용 UX 포함), 한 파일 `#chat` 전환
- 카피: 일반 상용 B2C 톤(도메인·종교 어휘 금지)
- 콘텐츠: 공통 팩(`_content.md`) — 같은 내용, 다른 디자인으로만 대조
