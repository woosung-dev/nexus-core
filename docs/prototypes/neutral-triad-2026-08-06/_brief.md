# 마스터 브리프 — neutral-triad 라운드 (2026-08-06, 7회차)

중립 상용 서비스("약관·규정·매뉴얼, 읽지 말고 물어보세요")의 랜딩+채팅 프로토타입 3안.
**콘텐츠·화면 스펙·하드룰의 유일한 정본은 `_content.md`다.** 이 브리프와 스킬 기본값이
`_content.md`와 충돌하면 `_content.md`가 이긴다.

스킬 배분: **ui = ui-ux-pro-max / fd = frontend-design / ts = taste-skill**, 안당 1방향.

## 이 라운드의 존재 이유

직전 6회차(blessing-unbound)가 전부 반려된 원인: **정체성을 크롬(레이아웃·은유·카피)에 넣었다.**
상용 레퍼런스는 반대다. 크롬은 중립 셸, 개성은 콘텐츠(봇·카피·표본 대화)가 낸다.
합격선: "이 셸에 어떤 도메인의 봇을 3개든 40개든 꽂아도 성립하는가."
그래서 방향명도 은유가 아니라 **스타일 서술어**다.

## 시장 조사 반영점 (요지 — 전문은 `_research/market-2026-08-06.md`)

- 히어로에 **인용이 보이는 실제 대화 화면**을 실물로. 로봇 마스코트·추상 그래픽 금지.
- 보라-파랑 그라디언트·다크테마 남용이 데이터로 입증된 1위 AI slop 신호. 팔레트는 2~3색 제약.
- Inter(=Pretendard 단독 획일) + 완전 중앙정렬 + 배지-H1-서브카피 공식 탈피. 통제된 비대칭 최소 1곳.
- 동일 padding 3열 아이콘 카드·좌측 컬러 보더 스트립은 낙인찍힌 신호.
- 가입 게이트 금지 — 콘텐츠 먼저, 가입은 액션 시점(Character.AI 반면교사).
- 태그가 검색 필터를 겸하는 로스터(제타 패턴). 카드엔 신뢰 신호만(담당 문서 수).
- 추상 약속("미래를 만드세요") 대신 구체 시나리오·구체 숫자.
- 모션은 의도된 마이크로인터랙션 1~2개만.
