  • 최근 3세션 카드 위 썸네일은 _shots/ 의 정적 캡처입니다. 눌러서 실물 페이지로 들어가야 해시 전환·팝오버 같은 동작을 볼 수 있습니다.
  • 3회차와 2회차는 해시가 #home/n40/dark/mobile 처럼 순서 무관 다중 세그먼트입니다. 1회차는 #home 한 조각입니다.
  • 브라우저가 다크 모드면 자동으로 다크로 뜹니다. 라이트를 보시려면 해시에 /light 를 붙이거나 각 화면 왼쪽 프로토타입 패널에서 「라이트」를 누르세요.
  • 왼쪽 검정 패널은 검토용 조종판입니다. 제품 UI가 아닙니다. 화면 폭이 1100px 미만이면 사라지고 우하단 동그란 버튼으로 열립니다.
  • 3회차 세 안은 노치 폰 목업을 쓰지 않습니다. 좁게 모드에서 반응형 실물로 렌더됩니다.
  • 봇 이름, 문서명, 판차, 규정 내용, 인용문, 계정 정보는 전부 UI 검토용 예시입니다. 실제 규정이나 승인 문서가 아닙니다.
  • README 링크는 마크다운 원문으로 열립니다. 브라우저에서 읽기 불편하시면 에디터에서 여시는 편이 낫습니다.
