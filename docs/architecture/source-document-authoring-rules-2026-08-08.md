# 원본 문서 작성 규칙 5가지 — 관리자 요청안

> 2026-08-08. 대상: 「규정집 v20」(조문 100개) · 「대사전 v4」(항목 150개).
> 근거: 모순 8건 관리자 판정 + 법제처 「법령입안심사기준」 + codex 교차검증.
> 이 문서는 **관리자에게 보낼 요청안**이다. 우리 쪽 작업은 §7 에 따로 있다.

## 왜 원본을 고치나

챗봇이 이 두 문서를 읽고 답한다. 문서는 사람이 읽을 것을 전제로 쓰여 있어서,
사람이 맥락으로 메우는 부분을 챗봇은 메우지 못한다.

실제로 챗봇이 신고한 모순 8건을 관리자가 판정한 결과, **틀린 신고 4건이 전부
"문서가 안 밝힌 것" 때문이었다.** 문서를 조금만 다르게 쓰면 사라지는 오류다.

---

## 실측 — 두 문서가 서로를 어떻게 가리키나

| | 결과 |
|---|---|
| 규정집 → 규정집 (번호로) | 거의 0곳 (제100조 개정이력표 7곳뿐) |
| 규정집 → 규정집 (이름만) | **23곳** ← 규칙 2의 대상 |
| 규정집 → 대사전 | 용어가 309번 등장, **참조 표시 0** |
| 대사전 → 규정집 | 6곳, 전부 이름. 번호 0 |
| 대사전 → 대사전 (`행정 NNN`) | 0곳 |
| 규정집 → 바깥 공문 (`근거:` 줄) | 20곳, **번호까지 정확** ← 여기만 잘 돼 있다 |
| 규정집 제3조와 대사전에 **같은 이름으로 양쪽 정의된 용어** | **23개** |

규정집은 바깥 문서는 정확히 가리키면서 **자기 안쪽과 대사전만 이름으로 부른다.**

## 규칙 1 — 조문 번호 고정

### 기존

```
제38조가 신설되자 → 뒤 62개 조문이 전부 +1 밀림
```

밀림으로 깨진 것은 규정집 **안**이 아니라 **밖**이다. 규정집 본문의 내부 인용은 원래 0이다.

- 과거 공문·회의록이 적어둔 조문 번호
- 챗봇/위키가 걸어둔 참조 800개 (그중 561개가 밀림 구간)
- 앞으로 규칙 2로 새로 달 23곳

### 원하는 결과

```
신설   제38조와 제39조 사이에 넣을 때  →  제38조의2   (뒤가 안 밀림)
삭제   번호를 빼지 말고              →  제38조  삭제  (번호 재사용 금지)
```

법제처는 가지번호를 **"가장 보편적으로 사용되는 방법"** 이라 하고, 밀어내리기의 단점을
이렇게 적어놨다.

> 기존 조문의 위치변경을 초래하기 때문에 벌칙조항 등 **다른 조문에서 위치 변동된 조문을
> 인용하고 있는 경우 이를 찾아서 반드시 같이 개정하여 주어야 하는 번거로움**

권하는 조건도 우리와 같다.

> 끌어내리거나 올릴 조문의 수가 너무 많거나, **다른 조문이나 다른 법령 중에서 많이 인용하고
> 있는 경우**에는 '가지번호 방식'을 고려해 볼 필요가 있다

## 규칙 2 — 조문 참조에 번호 + 관계 동사

### 기존

```
제39조 ③ 미혼 1세는 … 미혼 1세 축복후보자 심사기준 … 을 충족해야 한다.
```

이 이름의 조문은 목차에 **없다.** 진짜 제목은 `제19조(미혼 1세 축복후보자 기준)`.
같은 조문을 부르는 이름이 규정집 안에 4가지다.

```
제19조 진짜 제목   미혼 1세 축복후보자 기준
제39조 ③          미혼 1세 축복후보자 심사기준
제39조 ⑤          미혼 1세 심사기준
제39조 표          미혼 1세 축복심사 기준
```

### 원하는 결과

```
제39조 ③ 미혼 1세는 제19조(미혼 1세 축복후보자 기준)의 심사기준을 적용한다.
```

**판별 기준은 "번호의 유무"가 아니라 "다른 조문의 내용에 기대는가"다.**
`이 조`·`앞 항`·`같은 기준`·`별표` 도 전부 참조다. 기대는 문장이면 번호를 쓴다.

그리고 **관계를 동사로 구분한다.** 지금은 전부 "~에 따른다"로 뭉개져 있는데 효력이 다르다.

| 동사 | 뜻 |
|---|---|
| 적용한다 | 그 조문이 그대로 걸린다 |
| 준용한다 | 성격에 맞게 고쳐서 건다 |
| 예외로 한다 | 그 조문을 안 건다 |
| 참고한다 | 효력 없음. 읽어보라는 뜻 |

### 표기 방안 비교

| # | 쓰는 법 | 사람이 읽기 | 챗봇 | 유지 부담 |
|---|---|---|---|---|
| 1 | `제19조에 따른다` (법령 표준) | ★★★☆☆ | ★★★★★ | ★★★★★ |
| **2** | **`제19조(미혼 1세 축복후보자 기준)의 심사기준을 적용한다`** | **★★★★★** | **★★★★★** | **★★★☆☆** |
| 3 | `미혼 1세 축복후보자 기준(제19조)에 따른다` | ★★★★★ | ★★★★☆ | ★★★☆☆ |
| 4 | `미혼 1세 축복후보자 심사기준에 따른다` (현행) | ★★☆☆☆ | ★☆☆☆☆ | ★★★★★ |
| 5 | 참조를 없애고 제19조 내용을 여기 다시 씀 | ★★★★☆ | ★★★★★ | ★☆☆☆☆ |

**→ 방안 2.** 한국 법령 표준은 번호만 쓰는 방안 1이지만, 이 문서는 실무자가 찾아보는
지침서라 제목을 덧댄다. 대상이 23곳뿐이라 유지 부담이 작다.

방안 5는 금지한다 — 내용이 두 군데가 되어 나중에 서로 어긋난다. **지금 모순 8건이 이렇게 생겼다.**

괄호 안 제목은 **진짜 제목 그대로**여야 한다. 다르게 쓸 바에는 안 쓰는 게 낫다.

## 규칙 3 — 조문 첫머리에 「적용범위 / 다른 조문과의 관계」

### 기존

```
제17조(축복자녀 축복후보자 기준)        …만 20세 이상
제39조(축복자녀-미혼 1세 축복 자격)     …만 25세 이상
```

둘 다 "기준"이라고만 적혀 있어서 챗봇이 같은 저울에 올리고 **"서로 안 맞는다"고 잘못 신고**했다.
사실은 재는 것이 다르다 — 제17조는 **본인 한 사람의 자격**, 제39조는 **두 사람이 짝을 이룰 때의 자격**.

### 원하는 결과

```
제17조(축복자녀 축복후보자 기준)
  적용범위: 후보자 개인의 자격을 판단할 때 적용한다.
  다른 조문과의 관계: 제39조의 두 사람 단위 자격과는 별도로 적용한다.
```

**모든 조문에 붙이면 잡음이 된다.** 자격·금액·예외·절차처럼 오판 위험이 큰 조문부터 적용한다.

## 규칙 4 — 용어 정본을 규정집으로 못 박기

### 기존

같은 용어 **23개**가 규정집 제3조와 대사전 양쪽에 정의돼 있고, 어느 쪽이 맞는지 안 적혀 있다.

```
축복자녀 · 미혼 1세 · 축복후보자 · 상대확정 · 가정공과금 · 가정기금 · 독신축복
삼위기대 · 위로축복 · 은사 · 이관 · 금식정성 · 데스밸리 특별성염 · 하늘공관금 …
```

규정집은 **공문과의 우선순위는 이미 정해뒀다**(제2조② 별도 공문 우선, 제5조 최신 공문 우선).
**대사전과의 우선순위만 없다.**

### 원하는 결과

제3조 머리에 한 줄.

```
제3조(용어의 정리)
  이 조의 정의를 정본으로 한다. 대사전은 실무 설명과 별칭을 제공하며,
  뜻이 다를 경우 이 조를 따른다.
```

### 정본 선택 비교

| # | 방안 | 사람이 읽기 | 챗봇 | 유지 부담 | 위험 |
|---|---|---|---|---|---|
| **1** | **규정집 제3조가 정본, 대사전은 설명·별칭** | ★★★★★ | ★★★★★ | ★★★★☆ | 낮음 |
| 2 | 대사전이 정본, 규정집이 인용 | ★★★☆☆ | ★★★★☆ | ★★☆☆☆ | **높음** |
| 3 | 제3의 표준용어집을 새로 만듦 | ★★★★☆ | ★★★★★ | ★☆☆☆☆ | 중간 |

**→ 방안 1.** 대사전은 자기 머리에 "내부 참고본"이라 적어놨고 일부는 아직
`검토상태: 확인 필요`다. **미승인 문서가 자격·금액의 뜻을 정하게 두면 안 된다.**

23개는 먼저 문구를 대조해 **완전 동일 / 설명만 더함 / 뜻이 실제로 다름** 셋으로 가른다.
셋째만 사람이 판단하면 된다. "양쪽에 있다"는 이유만으로 합치면, 규정집의 좁은 정의와
대사전의 넓은 실무 정의를 성급히 뭉갤 위험이 있다.

## 규칙 5 — 대사전에 `규정상 정의:` 줄 추가

### 기존

대사전이 규정집을 가리키는 6곳이 전부 이름뿐이고, 대사전끼리는 번호로 아무것도 안 가리킨다.
별칭(`관련·기존 표기`)이 있는 항목은 150개 중 35개뿐이다.

### 원하는 결과

```
행정 122 축복자녀
  규정상 정의: 규정집 제3조        ← 추가
  관련·기존 표기: 2세               ← 35/150 → 가능한 만큼 채우기
  용어 설명 / 업무 참고
```

`검토상태` 필드는 그대로 유지한다. 우리 쪽에서 이 값이 미결인 항목은 챗봇이
근거로 쓰지 않도록 막을 예정이다(§7).

## 정리 — 관리자에게 부탁할 것

| # | 무엇 | 일감 |
|---|---|---|
| 1 | 신설은 `제38조의2`, 삭제는 `제38조 삭제` | 앞으로의 개정 약속 |
| 2 | 조문 참조에 번호 + 관계 동사 | **23곳** |
| 3 | 위험 조문 첫머리에 「적용범위 / 다른 조문과의 관계」 | 조문마다 한 줄 |
| 4 | 제3조에 용어 정본 선언 한 줄 + 23개 용어 대조 | 한 줄 + 대조 작업 |
| 5 | 대사전에 `규정상 정의:` 줄 | 항목마다 한 줄 |

규칙 1과 2는 **한 세트**다. 번호로 가리키려면 번호가 안 밀려야 한다.

## §7 우리 쪽 작업 (관리자 몫이 아니다)

관리자에게 넘기면 안 되는 것들이다. 문서 문제가 아니라 파이프라인·정책 문제다.

| 무엇 | 실측 |
|---|---|
| 페이지 머리말·꼬리말이 조문 본문에 끼어듦 | **76/250** (규정집만 47/100) — pdftotext 문제 |
| 표가 청크 경계에서 잘림 | 제59조 ①과 ③ 사이에 페이지 푸터가 낌 |
| `검토상태=확인 필요` 항목을 챗봇이 근거로 씀 | 모순 8건 중 3건이 이것 |
| 용어 309곳 연결 | 원본에 표시하지 말고 우리가 자동 연결 |
| v20이 승인 전 초안임을 답변에 표시 | 현재 미표시 |

**309곳을 원본에 일일이 표시하게 하면 안 된다.** 용어가 309번 나오는 것은 참조가 아니라
그냥 그 단어를 쓴 것이다. 전부 각주를 달면 사람이 읽을 문서가 망가진다.
사람용 본문에는 **조문별 첫 사용 1회**만 두고, 나머지는 우리가 연결한다.
